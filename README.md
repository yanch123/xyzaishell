# xyzaishell

左侧是 SSH 终端，右侧是 AI 对话。直接说需求，AI 生成命令、读取结果并继续分析；普通命令展示后自动执行，危险或风险不明的操作由你单次确认。

以下说明对应 **v0.1.4**，安装包是否已提供以 [Releases](https://github.com/yanch123/xyzaishell/releases) 为准。已发布版本请阅读其随附说明。

## 下载与安装

在 [Releases](https://github.com/yanch123/xyzaishell/releases) 的 Assets 中选择：

- **Windows x64**：下载 `.exe`，按向导安装。需要 WebView2，缺少时可能需要联网。
- **Ubuntu 22.04 / 24.04 x64**：下载 `.deb`，运行 `sudo apt install ./实际文件名.deb`，从应用菜单启动。

当前提供预发布测试版，安装包未签名。遇到系统安全警告请先核实来源，建议先在测试服务器使用。Windows 10/11 实机及完整桌面体验等未验证范围，以该版本发布说明为准。下载文件可用同页 `SHA256SUMS.txt` 核对。

## 三步开始

### 1. 连接服务器

点击“新建连接”，填写地址、端口、用户名，选择密码或本机私钥。首次连接先核对服务器指纹。

勾选“保存连接”可下次复用；只有另外勾选“记住密码／私钥口令”才保存凭据。Windows 使用当前用户系统保护，Linux 需要已解锁的 Secret Service，失败不会回退为明文。

一个窗口连接一台服务器。连接其他服务器默认打开独立窗口。

### 2. 配置模型

打开“设置 → 模型”，填写：

- **Base URL**：服务的 API 根地址，不要追加 `/chat/completions`
- **API Key**：服务密钥
- **模型名称**：服务支持的模型标识

使用兼容 OpenAI Chat Completions 的服务。点击保存或测试；已有 Key 留空会保留。Key 存在本机受限权限的明文配置文件中，请勿放入共享目录或聊天。

首次使用或接收方／目标范围变化时，会简短说明数据发送和自动执行范围。模型可能记录内容或收费；文字测试通过不等于支持执行所需的工具调用。

### 3. 直接聊天

无需切换模式，可以直接输入：

- “你好”
- “检查磁盘空间，告诉我哪里需要注意”
- “查看最近的服务日志，分析启动失败的原因”
- “根据刚才的结果，下一步该查什么？”

连接后，受支持的终端会自动准备。AI 会展示拟执行命令，读取实际结果，并继续处理；有风险的操作显示完整命令与影响，批准后才执行。不认识的程序不会仅因名称被一律禁止，但可能需要你核对风险。

如果终端环境、语法或交互方式暂不支持，会说明原因，不会假装执行成功。未连接时仍能聊天。Bash 兼容范围必须以该版本实际验收结果为准，不要求你为了试用随意升级服务器 Shell。

## 常用操作

- **停止**：点击“停止 AI”。这不会撤回已经执行的命令；要中断远端程序，使用左侧“发送 Ctrl+C”并核实结果。
- **分析选区**：选中终端文字，点击“选区交给 AI…”，删去敏感内容后发送。带选区的消息只做分析，不执行其中的指令。
- **搜索／复制／粘贴**：使用终端按钮或 `Ctrl+Shift+F`、`Ctrl+Shift+C`、`Ctrl+Shift+V`。粘贴先预览，换行可能执行命令。
- **日志导出**：“当前终端日志”查看当前会话；“连接管理 → 操作日志”查看指定连接。筛选并刷新后导出 JSON／CSV，结果显示本机文件路径。Bash 4.2 的手动操作仅标注观察缺口，AI 执行命令可记录。
- **历史与显示**：在设置中管理聊天历史、字号和回滚范围。日志和聊天历史默认关闭，启用后可能保存明文敏感信息。

AI 工作时请避免同时手动输入。密码或令牌使用任务专用秘密文件流程，不要粘贴到聊天；脱敏不能保证识别所有秘密。历史和摘要不是远端成功的证明，断线或执行结果未知时不要盲目重发。

更多操作和排错见 [v0.1.4 使用指南](docs/v0.1.4/05-user-guide.md)。反馈问题时提供版本、系统、脱敏错误和复现步骤，不要上传密钥、密码或含秘密的截图。
