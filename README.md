# xyzaishell

在一个窗口里使用 SSH 终端和 AI 助手：左侧连接服务器，右侧讨论问题或启动终端任务。AI 的命令会显示在同一个可见终端中，支持的普通命令可连续推进，危险操作需批准，未知状态会暂停。

以下使用步骤对应 **v0.1.3**。是否已有该版本安装包及其验证范围，以 Release 页面为准；v0.1.2 的操作见[旧版指南](docs/v0.1.2/08-user-guide.md)。

## 1. 下载与安装

前往 [GitHub Releases](https://github.com/yanch123/xyzaishell/releases)，选择对应版本的 **预发布测试版**，先阅读该版本的已知限制，再展开 Assets 下载安装包：

- **Windows x64**：下载 `.exe` 安装包，运行安装向导。程序需要 Microsoft WebView2；缺少运行时的电脑在安装时可能需要联网。
- **Ubuntu x64**：下载 `.deb`，在文件所在目录使用 `sudo apt install ./实际文件名.deb` 安装，再从应用菜单启动。目标系统为 Ubuntu 22.04／24.04，需要系统 GTK／WebKitGTK 运行依赖。
- 同一 Release 提供源码压缩包和 `SHA256SUMS.txt`。普通使用请选择安装包；下载后可核对 SHA256，校验和不等于代码签名。

**这是预发布测试版。Windows 安装包未签名，可能出现发布者或 SmartScreen 提示。Windows 10／11 实机、Ubuntu 完整桌面使用流程和外部模型供应商兼容性尚未完成验证。** 遇到安全警告时先停止并核实来源；请先在测试服务器上使用，不要直接用于关键生产操作。macOS、ARM、其他 Linux 发行版暂不在支持范围内。

## 2. 配置模型

打开“设置 → 模型”，填写服务提供方给出的 **Base URL、API Key 和模型名称**。Base URL 是 API 根地址，不要追加 `/chat/completions`。

- “保存”只写入本机配置，不发送模型请求。
- “保存并测试”先保存，再确认测试接收方和发送范围；可以选择文字聊天连接测试或模拟工具调用测试，均不携带聊天或终端内容，不执行命令。结果区分通过、不兼容与无法确定；文字测试通过不代表工具调用兼容，工具测试通过也不保证复杂任务成功。
- 已有 Key 留空保持不变；使用独立按钮清除。更换服务地址不能默认复用原 Key。
- 保存冲突或结果不确定时，先重新读取并核对。保存成功后测试失败不会撤销设置。

模型未配置不影响手动 SSH，设置面板不会锁住终端。API Key 仍以明文保存在受限权限的本机 `model.toml`；不要放入 Git、同步盘或共享目录，也不要粘贴到聊天中。

“高级配置与安全说明”提供实际路径、权限和重新加载入口。默认路径为 Windows 的 `%APPDATA%\xyzaishell\model.toml`，或 Linux 的 `$XDG_CONFIG_HOME/xyzaishell/model.toml`（未设置时为 `$HOME/.config/xyzaishell/model.toml`）。`XYZAI_MODEL_CONFIG` 可指定绝对文件路径，修改后需重启；重新加载不会切换路径。已有合法高级字段会保留，完整示例见 [model.example.toml](config/examples/model.example.toml)。

## 3. 登录 SSH 服务器

点击“新建连接”，填写主机、端口（默认 `22`）、用户名，选择密码或本机私钥认证。私钥填写本机绝对路径；加密私钥按需提供口令。

- 不勾选“保存连接”：只进行本次连接。
- 勾选“保存连接”：填写名称，保存资料后再连接；“仅保存连接”不连接服务器。
- 在保存资料基础上明确勾选“记住密码／私钥口令”，才持久保存凭据。Windows 使用当前用户系统保护，Linux 需要可用、已解锁的 Secret Service；失败不自动回退到明文。

首次连接或主机指纹变化时，通过可信渠道核对后再信任。“连接管理”可编辑、重命名、删除连接和查看日志；保存修改不自动连接。缺少凭据时按提示补输，默认只用于本次认证，不影响其他连接的保存策略。

一个窗口对应一个进程、一条 SSH 会话和一个 PTY。已有连接时，另一目标默认在独立进程窗口中打开，原窗口继续工作。明确选择“在当前窗口切换”才会请求停止 AI、断开旧连接；切换失败不自动恢复旧会话。私钥文件不会发送给模型。

## 4. 右侧对话与终端任务

**文字聊天**用于讨论和规划，只发送你主动发送的消息和当前聊天上下文，不自动读取终端或执行命令。

选中左侧输出后，点击“选区交给 AI…”，在文字聊天中核对来源、编辑敏感内容并确认本次接收方，再发送分析。选区最多 8 KiB / 200 行，裁剪会标注；发送包括当前聊天已有历史。编辑、重连、切换聊天或修改模型后需要重新核对，选区不会直接写入终端。

需要 AI 实际操作服务器时：

1. 先连接 SSH，完成登录，确认没有命令运行且已显示 Bash 命令提示符。点击“命令状态识别”，勾选确认后“启用命令识别”，等待“命令识别已就绪”。
2. 当前支持交互 **Bash 5.1 / 5.2** 的受限配置，常见 Ubuntu 提示符和默认历史选项可用；自定义 trap、提示符命令替换等配置可能不受支持。详细范围见[使用指南](docs/v0.1.2/08-user-guide.md#3-启用命令状态识别)。启用只在当前 Shell 添加临时识别，不安装软件、不改写启动文件、不新建干净子 Shell，也不自动开启日志。
3. 在右侧“执行终端任务”输入任务，点击“核对并开始执行”，核对模型、服务器和发送范围后授权。任务指令、模型分析、拟执行命令及本次运行开始后收集的有限终端输出会发送给模型服务；服务可能记录内容或收费。
4. 支持的普通字面检查和目录导航命令可自动继续；危险操作需核对完整卡片并单次批准。未知语法、命令结果未知或就绪证据失效时暂停，不能盲目重发。有效的命令识别会自动确认前台返回与下一次就绪，正常流程无需每条命令点击继续。

任务中可展开“已确认事实 / 剩余步骤”，查看有来源的排查结论、待验证推测和计划。摘要会供后续每轮分析使用，仅属于当前任务和连接；结论与步骤状态由模型整理，程序识别的命令返回单独显示。保留输出有上限，不能把摘要当完整日志。达到轮数上限时需核对结果再明确开始新任务，不会自动重发。

前台返回不等于后台任务或业务目标成功。多个聊天共享同一个终端，一次只有一个 AI 任务写入；请避免同时手动输入。“停止 AI”不撤回命令，也不自动发送 Ctrl+C；需要中断远端程序时使用终端独立的 Ctrl+C 操作。

AI 面板持续显示当前服务器及聊天来源。连接不同目标会创建新聊天；旧目标聊天及恢复历史只供阅读，不复用执行上下文或批准。重连同一目标可保留文本，但需重新建立命令识别。

## 5. 为任务填写密码或令牌

每个 AI 任务使用独立的本机秘密文件。需要凭据时，模型只提出字段名和用途：

1. 点击“准备本机秘密文件”，在本机编辑器中打开界面显示的文件，填写对应字段的 `value`。
2. 保存后点击“重新加载已填写状态”。模型只收到字段名、是否已填写等信息，不会得到秘密值或本机文件路径。
3. 需要输入远端时，先确认终端正在等待正确程序的密码输入，而不是普通 Shell 命令行。选择字段、填写用途并确认目标与回显风险，点击“核对本次秘密输入动作”，最后在卡片上批准本次输入。

秘密输入仅支持单行值并追加一次 Enter，不用于拼接 Shell 命令。修改／重载文件或更换连接后需重新核对。任务文件是受限权限的明文文件，编辑器备份和远端程序仍可能记录秘密；脱敏不能保证识别所有变形或未知秘密。不要在聊天或用途栏填写秘密值。详见[任务秘密操作说明](docs/v0.1/11-user-guide.md#5-任务中的密码和令牌)。

## 6. 可选的本机历史

聊天历史默认关闭，每次启动需在设置中明确启用。启用后将脱敏文字保存在本机明文数据库，不保存原始终端输出或可重放的授权。

恢复历史只恢复文字，不会重连 SSH、启动模型或重发命令。关闭历史只停止新增保存，不删除已有记录。单独移除记录需再次确认，逻辑删除不可恢复，也不保证物理擦除。存储位置与详细操作见[使用指南](docs/v0.1/11-user-guide.md#6-保存和恢复历史)。

## 7. 操作日志与导出

日志独立于 AI、默认关闭。开始新记录前，先通过工具栏启用“命令状态识别”并等待就绪，再在日志面板明确同意本机明文保存。日志面板不会自动启用或重装命令识别。不会默认启动干净子 Shell。

- “当前终端日志”查看当前会话；“连接管理 → 操作日志”查看所选连接历史；“查看 → 操作日志”查看全部记录。
- 可以按原主机、账号和关键词筛选。原目标与会话保留不变；缺少档案 ID 的旧记录显示“档案关联未知”，不会按名称猜测归属。
- “导出 JSON／CSV”导出当前筛选快照内的全部匹配记录，不限当前页；修改筛选后先刷新。结果显示本机私有目录中的完整路径，不覆盖旧文件，离线查看和导出不连接服务器。

命令可能含密码、令牌或业务信息。暂停记录不补录、不关闭正常工作的命令状态识别。默认不保存终端输出，也不自动发送日志给模型；脱敏不能保证识别所有秘密。CSV 对公式样式文本作安全处理，规范文本请选择 JSON。远端可修改环境或伪造事件，日志不是不可篡改审计。

## 常见问题

- **读不到模型配置**：核对设置中显示的路径、TOML 字段、文件权限，以及 `XYZAI_MODEL_CONFIG` 是否为绝对路径。修改环境变量后重启。
- **能聊天，不能执行终端任务**：先确认已连接 SSH、“命令识别已就绪”、没有其他任务占用终端；模型服务还需支持流式工具调用，聊天测试通过不代表兼容。
- **保存 SSH 凭据失败**：检查系统安全存储是否可用、是否已解锁。也可使用仅本次连接；不要反复覆盖保存结果不确定的档案，先重新读取状态。
- **AI 停下来等待确认**：先区分危险命令批准、等待前台返回和状态未知。核对实际终端，不把静默或等待当作成功，不重复发送结果未知的命令。
- **能传文件或操作本机吗？** 当前只通过 SSH 终端操作远端，不提供 SFTP、文件上传下载、本机 PowerShell 或 WSL。

更多操作说明见[v0.1.2 使用指南](docs/v0.1.2/08-user-guide.md)。反馈问题请提供应用版本、系统版本、脱敏错误码和复现步骤，不要上传真实 Key、密码、私钥、任务秘密文件或包含秘密的截图。

## 终端搜索与显示设置

点击“搜索”或按 Ctrl+Shift+F，搜索本窗口保留的终端输出，使用上一个／下一个定位，Esc 关闭。Ctrl+F、Ctrl+C 保留 Shell 原有行为。

复制选区使用按钮或 Ctrl+Shift+C；粘贴使用按钮或 Ctrl+Shift+V，核对预览与目标后再确认。换行可能执行命令，应用不额外追加 Enter，也不允许危险控制字符混入粘贴。

在“设置 → 终端”调整字号和回滚行数。缩小回滚范围会丢弃更早的屏幕显示，不会删除远端文件或操作日志。详见 [v0.1.3 新功能使用说明](docs/v0.1.3/05-user-guide.md)。
