# xyzaishell

面向 Windows 的 AI SSH 终端。左侧保留常规 SSH 终端，右侧提供类似 Cursor 的 AI 对话。AI 根据任务生成命令、通过同一个可见终端执行并分析输出，高风险操作需要用户授权。

## 当前状态

**文档阶段，版本 design-v0.1，日期 2026-10-13。** 本仓库目前没有应用实现、可运行演示或 Windows 安装包。本文档集记录已确认需求、建议技术方案、接口草案、验收标准和后续开发顺序；文档完成不代表接口已冻结、代码已编译或测试已通过。

## 产品边界

- 首个交付目标为 Windows 10／11 x64 安装包。
- 一个应用实例对应一个 SSH 会话，多台服务器通过多个实例连接。底层 WebView 可能产生辅助进程，不承诺一个窗口严格只有一个 OS 进程。
- 一个实例支持多个 AI 对话，每个对话作为独立任务，同一时间只有一个 AI 任务可以向终端写入。
- 用户手动输入始终可用。用户自行避免与 AI 同时操作，不提供自动人工优先、输入暂停恢复或接管协调。
- 只通过 SSH 终端命令操作；不提供本机 PowerShell／WSL、SFTP 或文件上传下载功能。
- 模型通过用户配置的 OpenAI 兼容接口接入；兼容能力需要逐项测试。
- Jev 等决策模型只预留接口，当前不接入；无法可靠判断时暂停该步，交由用户确认。

## 建议技术基线

Tauri 2、Rust／Tokio、React／TypeScript、xterm.js、russh、Rig，使用本地 SQLite 保存非秘密应用记录，以 TOML 表达配置。该组合是文档建议，依赖版本应在实施阶段做兼容性验证后锁定，不能把本文档当成已验证的依赖清单。
