# xyzaishell

把 SSH 终端和 AI 助手放在同一个窗口：左侧操作服务器，右侧讨论问题、解释输出，或让 AI 协助完成终端任务。AI 执行的命令会显示在左侧终端；支持的普通命令可自动继续，危险操作需要单次批准，状态不明确时会暂停。

本文介绍 **v0.1.4** 的使用方式。详细步骤见 [完整使用指南](docs/v0.1.4/05-user-guide.md)。

## 下载与安装

打开 [GitHub Releases](https://github.com/yanch123/xyzaishell/releases)，阅读所选版本的说明，在 **Assets** 中下载安装包。可下载版本及验证范围以该页面为准。

- **Windows x64**：下载 `.exe`，按安装向导完成安装。需要 Microsoft WebView2，缺少运行时的电脑可能需要联网安装。
- **Ubuntu x64（22.04 / 24.04）**：下载 `.deb`，在下载目录运行 `sudo apt install ./实际文件名.deb`，然后从应用菜单启动。需要系统 GTK / WebKitGTK 运行依赖。
- 普通使用请选择安装包，而不是 Source code。可用同一版本的 `SHA256SUMS.txt` 核对下载文件；校验和不等于代码签名。暂不支持 macOS、ARM 和其他 Linux 发行版。

**当前为预发布测试版。Windows 安装包未签名，可能出现发布者或 SmartScreen 提示；遇到安全警告请先停止并核实来源。Windows 10 / 11 实机、Ubuntu 完整桌面流程及外部模型服务兼容性尚未完成验证。请先使用测试服务器，不要直接用于关键生产操作。**

## 快速开始

### 1. 连接服务器

点击“新建连接”，填写主机、端口（默认 `22`）和用户名，选择密码或本机私钥认证。使用私钥时填写本机绝对路径，加密私钥还需口令。点击“连接服务器”，首次连接或主机指纹变化时，先通过可信渠道核对指纹，再决定是否信任。

希望下次复用时，勾选“保存连接”并填写名称；“仅保存连接”只保存资料。之后从“连接管理”打开、编辑或删除连接。

**保存连接不等于保存密码。** 只有明确勾选“记住密码”或“记住私钥口令”才会持久保存凭据：Windows 使用当前用户系统保护，Linux 需要可用且已解锁的 Secret Service，失败不回退到明文。本机账号或系统被控制时仍有风险，不放心时只用于本次连接。私钥文件不会发送给模型。

一个窗口连接一台服务器。已有连接时，另一目标默认在新窗口打开；选择“在当前窗口切换”会断开旧连接，切换失败不会自动恢复。

### 2. 配置 AI 模型

打开“设置 → 模型”，填写服务提供方给出的三个字段：

- **Base URL**：API 根地址，不要追加 `/chat/completions`
- **API Key**：该服务的密钥
- **模型名**：服务支持的精确模型标识

需要 OpenAI-compatible Chat Completions 服务。“保存”只保存到本机；“保存并测试”会先保存，再请你核对接收方和测试范围。可选择“文字连通性”或“任务工具调用”；测试不携带聊天和终端内容，也不执行命令。聊天测试通过不代表能执行任务，工具测试通过也不保证复杂任务成功。

API Key 以明文保存在受限权限的本机配置文件中，不要放入同步盘或共享目录，也不要粘贴到聊天。已有 Key 留空保持不变，清除需使用专用按钮。未配置模型仍可手动使用 SSH。

### 3. 直接对话，让 AI 协助操作

右侧只有一个对话输入框，不需要切换聊天与任务模式：

- “你好”：正常回复。
- “检查磁盘空间并解释结果”：在终端准备就绪后，展示检查命令并自动执行，再分析结果。
- 涉及删除等危险操作：展示完整命令与风险，批准后才执行。

首次使用或更换模型配置／目标服务器时，核对接收方、数据范围及普通命令自动执行许可；不再每次弹任务启动确认。执行时会发送当前聊天的有限历史、指令、命令及有限终端输出，服务可能记录内容或收费。

支持的 SSH 环境连接后自动准备命令识别。顶部状态可查看结果；无需另外点击启用。当前验证范围为 Bash 5.1 / 5.2 的受限配置，使用读取 `.bashrc` 的非登录交互 Bash，不改写远端启动文件；与原登录 Shell 的 profile 行为可能不同。准备中或环境不支持时仍可聊天和手动操作，不会把本轮请求自动排队后重发。详见[自动准备与兼容范围](docs/v0.1.4/05-user-guide.md#5-连接后的自动准备)。

任务中可查看“已确认事实 / 剩余步骤”和命令记录，后续追问可参考前文。模型结论不代表独立核验，退出码为 0 也不保证业务成功。

选中终端文字，点击“选区交给 AI…”，审阅来源、内容和接收方后可发送分析。每次最多 8 KiB / 200 行，包含当前聊天历史；带选区的消息只做分析，不执行选区里的命令。希望执行建议时再单独提出需求。

**“停止 AI”不撤回已发送命令，也不自动中断远端程序。** 如需中断，使用终端“发送 Ctrl+C”并核实结果。AI 工作时避免同时手动输入。任务需要密码或令牌时，使用[任务秘密文件流程](docs/v0.1.4/05-user-guide.md#7-任务中的密码和令牌)，不要填进聊天。

## 常用操作

- **搜索输出**：点击“搜索”或按 `Ctrl+Shift+F`，用上下按钮定位，`Esc` 关闭。只搜索本窗口保留的输出，不搜索远端文件。
- **复制 / 粘贴**：使用“复制选区” / “粘贴…”或 `Ctrl+Shift+C` / `Ctrl+Shift+V`。粘贴需核对预览与目标；换行可能执行命令，应用不会额外追加 Enter。`Ctrl+C` 仍用于终端中断。
- **字号与回滚**：“设置 → 终端”。缩小回滚行数会丢弃更早的屏幕内容。
- **操作日志**：“当前终端日志”看当前会话；“连接管理 → 操作日志”看该连接；“查看 → 操作日志”看全部。记录默认关闭，需等待命令识别准备就绪，再明确同意本机明文记录。
- **导出日志**：在日志面板筛选并点击“筛选 / 刷新”，再“导出 JSON”或“导出 CSV”。导出的是当前查询快照中全部匹配记录，不限当前页；完成后显示本机文件完整路径。浏览、导出离线记录不会连接服务器。
- **聊天历史**：“设置 → 历史记录”中启用。默认关闭，每次启动需重新选择；恢复只恢复文字，不重连或重放命令。

日志、启用后的聊天历史和任务秘密文件均可能包含本机明文敏感信息；脱敏不能保证识别所有秘密。日志不保存终端输出，也不自动发送给模型。停止记录不删除旧数据；移除聊天历史不可恢复，且不保证物理擦除。详见[历史与隐私说明](docs/v0.1.4/05-user-guide.md#10-聊天历史与隐私)。

## 常见问题

**能聊天，为什么不能执行任务？** 先确认 SSH 已连接、终端自动准备就绪，且没有其他 AI 任务占用终端，再测试“任务工具调用”。准备中或环境不支持时仍能聊天，但不会执行命令。

**记住密码失败怎么办？** 检查系统安全存储是否可用、已解锁，或改为仅本次连接。若提示保存结果不确定，先重新读取状态，不要反复保存覆盖。

**AI 停住了，要再发一次命令吗？** 先看是在等待危险操作批准、命令结束，还是状态未知。核对左侧终端；静默、断线或关闭提示都不代表执行成功，结果未知时不要重发有副作用的命令。

**可以传文件、操作本机吗？** 当前通过 SSH 操作远端，不提供 SFTP、文件上传下载、本机 PowerShell 或 WSL。

更多设置、故障处理和安全边界见 [v0.1.4 完整使用指南](docs/v0.1.4/05-user-guide.md)。反馈时请提供应用版本、系统版本、脱敏错误码和复现步骤，不要上传 Key、密码、私钥、任务秘密文件或含秘密的截图。
