# 05 — 终端日志使用说明

本页描述 v0.1.1 的终端日志功能；是否已有可下载安装包，以 GitHub Release 页面为准。

## 开启记录

1. 连接 SSH。确认左侧是空闲的 POSIX 兼容 Shell 提示符，没有在编辑器、密码提示或正在运行的命令里。
2. 打开侧边栏「终端日志」，阅读本地明文与 Shell 支持范围提示，勾选记录同意和终端就绪确认。
3. 点击开启。应用在同一个可见终端启动 Bash 4.4+ 日志子 Shell；还需要远端 base64、tr、env 等基础命令。
4. 只有收到握手后才显示「Shell 报告记录中」。初始化失败或超时不会自动重发命令，应检查终端并重新连接后处理。

此功能不需要配置模型。手动与 AI 输入均由这个 Shell 的同一通路采集，不推测来源。启动新的日志子 Shell 不继承父 Shell 未导出的函数、alias 或交互配置，也不改写远端启动文件。

## 查看与导出

日志显示本机收到开始事件的时间、远端自报 Unix 秒、连接信息、执行前物理目录、完整顶层命令及可观察到的返回状态。可按关键词筛选和分页。

- 「已开始，尚未记录结束」不证明命令现在仍在运行；应用异常退出或其他实例可能尚未写入结束信息。
- 收到返回事件只表示该 Shell 返回提示符；返回码 0 与非零分别显示，后台子进程结束不在保证范围。
- 一条 `cd /tmp; pwd` 的目录是整个顶层命令开始前的目录，不是中途的 `/tmp`。脚本内部命令不展开。

JSON/CSV 导出覆盖当前筛选范围，不仅是当前显示的一页。文件保存到本地私有的 shell-log-exports 子目录，完成后显示实际路径，可复制后在文件管理器中找到。每次创建新文件，不覆盖旧导出。

JSON 保留规范文本结构；CSV 对可能触发表格公式的文本加安全前缀，因此不是逐字节的原始命令文件。不要把导出文件当脚本执行。未开始保存且没有日志数据库时，导出会提示暂无可导出记录。

## 暂停与范围限制

执行可能含秘密的命令前暂停记录。暂停期间的命令不会在恢复时补录。密码提示中的按键不作为命令记录；但直接把密码、令牌写进命令或 heredoc 仍可能成为日志。已知秘密过滤不能保证识别未知或编码后的秘密。

默认不保存终端输出正文。日志不会自动发送给模型，但日志文件和导出均为本地明文，应自行保管。

首期只记录显式开启的这一层 Bash。进入嵌套 Shell、sudo -s、其他服务器的 ssh、tmux、编辑器或 REPL 后，其内部操作不属于本期完整记录范围。退出子 Shell 会回到父 Shell；再次开启需重新连接。断线后不自动恢复日志模式。

history 设置改变、非法或超大元数据、存储故障、记录上限会显示缺口或停止。用户/远端程序可禁用 hooks 或伪造事件，不能把这些记录当不可篡改的服务器审计。
