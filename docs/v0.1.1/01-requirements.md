# 01 — v0.1.1 终端命令日志需求

状态：已实施，开发验收中，未发布。该版本在 v0.1.0 上增加独立于模型的 Shell 操作记录与导出。

## 用户目标

查看并导出「什么时间、在哪个远程目录、执行了什么命令」。手动输入和 AI 写入最终由同一个 Shell 执行，因此使用同一采集通路；不依赖模型配置、模型响应或聊天历史。

## 本期范围

- 用户明确启用后记录；默认关闭，显示本地明文存储与命令可能包含秘密的提示。
- 首期以显式启动的受控 Bash 子 Shell 集成为目标，复用当前可见 SSH PTY，无隐藏 SSH exec 或文件传输，不改写远端启动文件。
- 记录完整顶层命令、执行前远程工作目录、事件时间、连接信息，以及在可以观察到时记录结束状态。
- 独立本地日志列表和分页查看；支持 CSV 与 JSON 导出。
- 开关、错误、采集缺口、未知结束状态必须可见。无法可靠识别的数据不得猜测。
- 日志只作为用户查看的数据，不自动发给模型，不重放命令，不恢复运行或授权。

## 不在默认范围

不记录按键流、密码提示输入或终端输出正文。用户尚未选择是否需要输出正文，此项不作为当前命令日志的前置条件。不能保证识别命令中所有未知或编码后的秘密，用户执行敏感命令前应暂停记录。

不把会话更新时间当执行时间、不从终端提示符推断目录、不把向 SSH 写入成功当远程执行成功。不将 Shell 自报事件描述成防篡改审计，远端进程可伪造数据或禁用集成。

## 验收方向

在未配置模型时，通过真实 OpenSSH PTY 覆盖手动命令、目录切换、引号与中文、多行、管道、heredoc、失败命令、交互式输入、退出、断线、暂停与重连。导出记录必须与界面及持久化内容一致，恶意文本不得变成 HTML、表格公式、路径或可执行动作。

所有新增文档在 docs/v0.1.1 下编号；开发阶段按小阶段提交 dev，测试后再处理版本发布。
