# 04 — 验收计划

状态：待实施与验证，不能把此计划当通过证据。

1. 协议单元测试：所有分块位置、粘连、无效 Base64/UTF-8、超限、错误 nonce、重复乱序、未结束帧、恶意控制序列；无内存失控或执行副作用。
2. 真实 OpenSSH PTY：无模型配置时的手动命令；同 PTY AI 写入的命令；cd 前目录、失败 cd、中文/空格目录、引号、编辑后提交、历史召回、多行、管道、heredoc、失败返回码、密码 read、交互程序、exit/断线。
3. 集成边界：不支持的 Bash 版本、初始化失败、history 禁用/过滤变化、嵌套 Shell、后台作业、hooks 被改写。不保证记录未收到的事件，不以猜测填补。
4. 存储：默认关闭、暂停后旧 epoch、不补录、容量/队列满、损坏库、多进程、锁冲突、Windows/Linux 私有权限、重启后只读恢复。
5. 导出：JSON/CSV 与查询一致，中文/emoji/换行/逗号/引号、所有文本列公式防护、路径安全、新文件拒绝覆盖、失败不报成功、快照一致性。
6. UI：模型不可用时独立使用；明确同意和终端就绪确认；重复点击、关闭重开、过时请求、断线、保存错误与导出实际路径。
7. 原生安装包：Windows/Linux 构建与实际安装后入口、持久化和导出；v0.1.0 → v0.1.1 升级保留原档案与聊天，不能用同版本重装替代升级。
8. 发布：只用最终候选精确提交的验证结果，提供源码和两平台安装包，保留未实测桌面范围，不修改已发布的 v0.1.0 标签或附件。
