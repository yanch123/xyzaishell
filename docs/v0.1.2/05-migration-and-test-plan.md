# 05 — 迁移与测试计划

状态：待执行计划，不是测试通过证据。本轮不运行新功能验收，也不接触真实凭据。

## 1. 迁移原则

连接文件若从全局保护模式改为逐档案策略，需明确的新 schema；具体版本号和字段在评审后确定。模型文件优先沿用现有兼容字段，新增可编辑 UI 不构成重写用户设置的理由。

迁移在受限目录中按锁、版本核对、受保护旧版副本、转换校验、安全替换、重新读取的顺序执行。成功后保持 ID、标签和服务器资料稳定；失败不覆盖唯一旧版，不自动退回明文，不自动连接或发送模型请求。结果未知先核对实际文件。仅在旧备份与凭据引用均完整、没有后续新版本写入且无其他写入者时，才可显式恢复；不能把文件回退等同于跨存储完全回滚。

| 旧数据／环境 | 迁移与恢复方向 |
| --- | --- |
| Windows DPAPI／Linux Secret Service 且有凭据 | 保留密文／有效引用及系统保护意图；不为迁移而把秘密导出前端或明文文件 |
| 平台保护模式下仅有资料 | 转为按需询问；保存资料继续可用 |
| 全局 `session_only` | 所有档案保留资料、按需询问；不猜测／恢复已丢失秘密；用户逐个重新输入并选择记住 |
| 系统存储锁定、缺失或拒绝 | 保留原引用与策略，提示恢复或明确临时输入；不能批量降级 |
| 换机器／跨平台复制 | 保留可验证的资料；不宣称 DPAPI／keyring 可移植，重新核对私钥路径并录入凭据 |
| 未知版本、损坏文件、并发修改 | 停止迁移并给出脱敏定位，不静默重置或覆盖 |

迁移不改 known_hosts、任务机密、聊天库和 Shell 日志；不能用相同名称重新创建档案后破坏原 ID 关联。老程序不应写回新 schema；降级默认不承诺自动兼容，恢复必须核对备份、版本和凭据可用性。

## 2. 验收矩阵

| 编号／关联需求 | 必测场景 | 通过标准 |
| --- | --- | --- |
| T1／R2 | 首次填写、保存、重启；编辑模型名保留旧 Key；替换／清除 Key | 无手工文件前置步骤；旧 Key 不回填；保存与生效状态准确 |
| T2／R2、R6 | 修改 Base URL；复用或替换 Key；迟到授权；重定向 | 新目标不静默得到旧 Key／上下文，旧确认失效 |
| T3／R2 | 未保存草稿测试、取消、超时、认证失败、SSE 成功 | 不自动保存、不带历史；只报告实测聊天范围，零 SSH 动作 |
| T4／R2、R7 | 高级字段、环境变量覆盖、错误文件、权限、外部修改、并发保存及断电边界 | 合法高级配置保留；路径无静默回退；冲突／不确定可恢复 |
| T5／R3 | 仅连接、保存、保存并连接、手动重连；保存成功但网络失败；重复点击 | 三种语义一致，无隐式保存、重复认证或假成功 |
| T6／R3、R4 | 无密码档案重启后连接；加密／无口令私钥；取消和重试 | 恰当询问凭据；输入不落盘，取消无副作用 |
| T7／R3、R4 | 编辑标签、认证目标变更、移除秘密、删除、两个不同策略档案 | 保留未改凭据，身份变更重新核对；其他档案不受影响 |
| T8／R4 | Windows DPAPI 与 Linux Secret Service；锁定、缺失、拒绝、恢复 | 不明文回退；资料可保存、用户可选临时连接、恢复后可逐档案记住 |
| T9／R7 | 旧平台模式、有／无秘密、旧 session_only；中途失败、跨实例、未知版本 | 信息与 ID 保留；不恢复丢失秘密；无自动网络活动或破坏性回退 |
| T10／R1、R5 | 菜单／工具栏／双击／右键／键盘、焦点、窗口缩小、关闭重开 | 同一状态来源，终端不被普通提示抢焦点；可取消、可恢复 |
| T11／R5、R6 | 主机密钥、风险命令、接收方、未保存编辑、历史与日志启用 | 决策仍明确且绑定对象；已读／关闭／测试成功不能批准 |
| T12／R6、R7 | 消息、错误、日志、截图和导出；聊天／Shell 日志回归 | 无测试秘密泄漏；消息与日志职责分开；既有安全约束保留 |

## 3. 分层证据与测试数据

单元测试验证配置更新意图、状态转换和错误映射；前端组件测试覆盖交互、重复点击与迟到响应；集成测试验证真实文件保存、SSH 和平台凭据；原生安装验收验证打包后的 UI 到 Rust 路径。各层不能相互代替。基线入口见[测试说明](../../crates/xyz-core/tests/README.md)与[原生验收范围](../../.github/NATIVE-ACCEPTANCE.md)。

所有测试使用一次性隔离目录、合成 Key／密码、临时 SSH 密钥、受控回环模型和测试 SSH 服务，不读取真实用户配置、keyring 或服务器，不向真实模型服务发送数据。截图／日志也只含合成数据；清理仅限测试创建的资源。

最终对同一候选提交分别记录 Windows／Linux、真实凭据提供者、旧 v0.1.1 数据升级和安装后流程的通过／失败／未测项。现有 v0.1.0→v0.1.1 升级证据不能替代 v0.1.1→v0.1.2；同版本重装也不能替代版本升级。CI、测试替身和 Xvfb 不足以声称所有真实桌面交互已验收。
