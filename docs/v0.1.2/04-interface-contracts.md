# 04 — 接口契约提案

状态：语义草案，未冻结、未实现。以下名称用于讨论，不表示已有对应 IPC，也不要求照此新增所有命令。

## 1. 模型设置能力

| 操作 | 必要输入与结果 | 关键约束 |
| --- | --- | --- |
| 读取设置摘要 | 字段值、Key 是否存在、文件来源／版本、就绪及确认状态 | 不返回 Key、可逆遮罩或秘密裸哈希 |
| 保存设置 | 期望文件版本、编辑字段、Key 更新意图；返回实际保存版本与摘要 | 保留高级字段；不发送网络请求 |
| 保存并测试／测试已保存配置 | 确定已保存版本、绑定目标的确认；分别返回保存与测试结果 | 保存失败／未知不测试；不测试未保存草稿或携带聊天 |
| 重新加载 | 当前选定路径；返回新摘要和错误 | 有未保存编辑先由 UI 处理；不换环境变量路径 |

Key 更新意图显式区分 `keep`、`replace`、`clear`。`keep` 由后端保留旧值；新建无旧值时不能假装配置完整。`replace` 只接收新输入。`clear` 必须显式确认并令发送不可用，不能悄悄留着旧授权。端点变更不能用普通 `keep` 隐式复用旧 Key，需明确的“将已有 Key 用于新目标”决定并绑定新版本；实际发送还需目标和数据范围确认。

配置修订与文件并发版本不能混为一个来源不明的编号。测试结果绑定所测目标、模型和已保存版本；后续编辑不能沿用为草稿通过，后续保存改变相关内容则使结果失效。修改／保存、已测试、已确认接收方、可启动终端任务是不同状态。

## 2. 档案与连接能力

| 操作 | 必要语义 |
| --- | --- |
| 列表／详情 | 稳定档案 ID、元数据、逐档案策略、凭据存在状态、后端可用性、修订；不返回秘密 |
| 保存／重命名 | 期望修订与明确凭据更新意图；非认证字段编辑默认保留原凭据 |
| 删除／移除秘密 | 指定档案、期望修订和明确决定；区分元数据提交与凭据清理结果 |
| 准备连接／新窗口 | 核对最新档案、目标进程与单连接状态；另一目标默认新进程，当前窗口切换需明确意图 |
| 提交临时凭据 | 绑定档案／草稿、修订、目标、认证方式和本次尝试；默认不持久化 |
| 新建并连接 | 接收保存资料／记住秘密选择；若需保存，先取得确定结果再连接；编辑档案保存不连接 |

连接准备不能返回可供模型使用的秘密句柄。输入挑战被取消、档案被修改、目标改变或连接代次变化后失效；迟到输入不得用于别的档案。记住密码写入成功与 SSH 认证成功分别返回，不能互相推断。安全存储不可用时，临时输入分支需用户选择，不修改原持久引用或其他档案。

## 3. 生命周期、上下文与日志范围

- 生命周期信封建议包含协议版本、SSH session／generation、Shell 实例、序号及事件类型，动作关联由宿主核对，不能直接信任远端 action_id 或来源声明。begin／end／exit_code 与独立 `shell_ready` 证据分开，过时、缺失或冲突事件使相关状态未知。具体 wire format 未冻结。
- 自动派发需宿主持有当前动作与风险判断、匹配就绪证据及必要的一次性批准。远端事件没有 approve／dispatch 能力；普通／危险／未知分类是待实现能力，不是旧白名单改个标签。
- 聊天摘要携带可验证的来源目标／会话；当前执行目标单独读取。恢复历史不自动迁移来源上下文，不恢复运行或授权。
- 日志查询明确 scope：当前会话、档案历史或全部，并携带相应筛选。档案历史同时保留记录原目标，目标变化不能混作当前服务器；profile_id 可空，旧记录不可根据现有档案反推。
- 日志查询与 CSV／JSON 导出复用明确范围和固定筛选快照，导出覆盖全部匹配记录而非一页，离线可用；不改变连接或记录开关。
- 日志消费者的开关、采集状态与执行集成状态分别返回；“日志已暂停”不能被 UI 翻译成“执行集成已停止”。详见 [07 — 自动执行与当前 Shell 集成](07-auto-execution-shell-integration.md)。

## 4. 状态、错误与兼容

沿用现有安全错误结构 `{code, safe_message, request_id, retry}` 的方向，按需加安全字段定位。既有 `CONFIG_CONFLICT`、`CONFIG_SAVE_UNCERTAIN`、`CREDENTIAL_MISSING`、`CREDENTIAL_LOCKED`、`CREDENTIAL_UNAVAILABLE`、`CREDENTIAL_ACCESS_DENIED` 等应映射到可操作提示，而非全部显示成同一存储失败。

消息包含操作 ID、来源、级别、摘要及可选帮助入口；只引用受控动作，不接受模型／远端提供的任意本机命令。保存请求重复提交、连接尝试重复发起和旧事件乱序必须可区分。状态未知只提供重新读取／核对，不以通用“重试”按钮覆盖数据。

新旧接口如何过渡、连接 schema 版本、清除 Key 后的文件表示，以及 SSH 目标／私钥变化时的明确复用契约，应在实现前评审。旧全局 `set_credential_mode(session_only)` 不再作为普通用户流程；不能仅隐藏按钮而保留新旧写入路径互相破坏数据。
