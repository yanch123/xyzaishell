# v0.1.2 模型设置与聊天来源阶段

本文件记录已实现的契约与验证，不代表已发布或已通过 Windows / Linux 打包验收。

## 模型设置

- 非模态设置面板提供“模型 / 通用 / 历史记录”导航。历史页复用原有明文历史启用与恢复流程；打开设置不锁住终端。
- UI 仅编辑 Base URL、API Key 与模型名。Key 输入框永不回填旧值；保存请求明确发送 keep / replace / clear。清除有独立确认，文件中写入 `api_key = ""`，使新请求不可用。
- 已有合法 TOML 的 capabilities、request、transport 字段完整解析并保留。保存会重新排版 TOML；不保证保留注释或原字段顺序。未知 schema、未知字段、损坏文件及不安全文件停止写入，并要求修复 / 重新读取。
- 路径在进程启动时固定，`XYZAI_MODEL_CONFIG` 错误不回退。安全读写复用 PrivateDirectory：私有目录与文件检查、稳定跨进程锁、精确已读字节比较、同目录受限临时文件、原子替换和写后核对。非协作编辑器仍可能竞争最后一次替换；异常或无法确定提交结果时停止后续保存 / 测试，要求重新读取。
- file_revision 是随机不透明 CAS 标识，后端关联精确文件字节，既不是秘密哈希，也不是运行状态 revision。保存请求需要 expected_file_revision，运行状态 revision 仅用于事件顺序。
- Base URL 变化且保留旧 Key 时必须显式提供规范化新目标对应的 reuse_key_for_destination。更换模型、Key 或地址后保存成功均撤销原聊天接收方确认。
- 保存不联网。保存并测试先确定保存成功，再显示目标、模型、最小数据范围的确认。失败 / 冲突 / 不确定保存不发测试。
- 测试只使用已保存且确认的不可变快照：认证 Key、一个 `Reply with OK.` 用户消息、最多 16 输出 token；无聊天历史、终端上下文、行为前言或工具。测试不新建聊天，不授予聊天或终端上下文授权。
- 测试结果绑定 test_id、file_revision、destination、model。测试期间保存新配置不会改变原请求；旧结果会标为旧版本。取消与超时均不重试，取消先于启动到达的 IPC 竞争也不会随后发送。
- 明确区分“已保存，测试失败 / 已取消 / 待确认”。测试通过仅证明该次流式文本响应，不声称工具调用兼容。

新增宿主 IPC：save_model_config、test_model_config、cancel_model_config_test。已有只读配置、重载与聊天接收方确认接口保留；旧 probe 兼容入口不再由设置页调用。

## 聊天来源与归档迁移

- ChatSnapshot 增加 source 与 restored_read_only。source 包含采集时 host、port、username、session_id、generation，由宿主实际 SSH 快照构造，不接受 UI 伪造目标字符串。
- 首次连接或更换服务器 / 账号创建空白新聊天；同目标重连保留文本及原始来源，但执行仍绑定新的 SSH 代次。初始化读取已存在的同目标活动聊天时不会重复创建。
- 不同来源目标的聊天仅可阅读，原来源不被当前连接覆盖。恢复的历史强制只读；后端拒绝发送及终端执行，不恢复运行句柄、批准或 Shell 状态。
- 历史 SQLite 格式由 v1 升到 v2，表结构保持不变。仅对精确已知 v1 表结构及旧载荷进行事务迁移，核对旧记录后更新版本；旧数据无 source 时仍为空，不推断关联。旧应用对 v2 明确拒绝，不能宣称无损降级兼容。
- 来源 host / username 与正文一起经过已知秘密脱敏，session_id 要求规范 UUID。恢复再应用新学到的秘密过滤。
- 读取历史不回写旧记录；在秘密尚未知时已写入磁盘的旧明文可能保留。新读取 / 新写入被脱敏，不保证抹除历史磁盘副本。

## 已执行验证

- 设置组件与 hook：保存意图、目标 Key 复用、清除确认、先保存后最小测试、失败分离、模糊提交禁止重试、外部变更不覆盖草稿、关闭 / 重载丢弃确认、取消测试、旧测试结果失效，以及目标改变 / 同目标重连 / 迟到新聊天回复隔离。
- 模型配置单测：新建与空 Key、完整高级字段保留、私有权限、Key 不回传、损坏 / 未知 / 不安全配置拒写、多实例 / 编辑器 CAS 冲突、目标绑定复用、准确已保存版本测试确认。
- 真实 loopback HTTP 集成：固定最小测试不带历史、不授予聊天授权；401 只判测试失败且保存保留；取消前置 / 流式中取消不重试；测试期间保存 / 清除 Key 保持原请求快照。
- 历史测试：v1 → v2 保持原 ID 与文本、旧数据无来源、不认识的 v1 载荷拒绝迁移且字节不变、来源秘密脱敏、恢复只读、新聊天无旧上下文、原有 SQLite 并发 / 事务 / 私有文件回归。
