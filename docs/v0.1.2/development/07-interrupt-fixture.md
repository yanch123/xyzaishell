# 07 — 发布复验中的终端中断测试同步修正

原测试在收到 Begin 前缀后，只等待 PTY 前台进程组不同于 Bash PID。PS0 内的命令替换可能短暂符合此条件，不能证明实际测试程序已经启动并设置好信号处理。发送 Ctrl+C 后，测试只收到了剩余 Begin 帧，没有预期的完成帧与提示符。
