# 06 — 整合开发阶段验证

日期：2026-10-14。此记录描述开发检查，不表示 v0.1.2 已公开发布。

## 实现范围

- 独立非模态模型设置、保存与保存后测试、明确 Key 处理。
- 连接资料与逐档案凭据保存、缺失凭据补输、独立进程新窗口。
- 当前 Bash 临时集成、普通命令自动执行、危险动作精确单次授权。
- 聊天目标来源及只读恢复、按连接或会话筛选的独立操作日志。
- 旧档案和聊天迁移、Windows/Linux 原生安装验收脚本。

## 本地检查

Rust 核心完整测试：225 个单元测试、19 个模型 HTTP 测试、19 个 SSH 回环测试、10 个 Agent 集成测试通过。3 个依赖系统凭据环境的单元测试及 2 个真实 OpenSSH 测试在普通运行中被忽略，由对应专用环境执行。严格核心 Clippy 与格式检查通过。

前端完整测试和生产构建、流水线 Python 辅助测试单独执行。最终数量及托管平台结果以精确提交的 CI 运行和后续验收记录为准，不把较早工作区结果当作后来提交的永久证明。

本机缺少 GTK/GLib/WebKit 开发依赖，桌面宿主的本机编译未完成；本机 Chromium 沙箱启动受限。Windows/Linux 宿主编译、实际安装、原生 DOM/IPC、升级和浏览器截图必须由托管 CI 验证，不用核心测试或模拟界面代替。

## 交付边界

用户授权测试通过后由 dev 合入 main 并发布源码、Windows NSIS 和 Linux DEB。未签名安装包及未完成的 Windows 10/11 实机、Linux 完整桌面验收需在 Release 如实披露；不能将托管 runner 的自动测试写成人工实机通过。
