# 01 — 操作日志归属存储基础阶段

日期：2026-10-14。此阶段仅实现日志存储基础，不表示整个 v0.1.2 已完成或可发布。

## 已完成

- 日志条目新增可空的不可变 `profile_id`；旧记录及尚未绑定档案的记录保持未知，不按连接名称猜测。
- SQLite schema 从 1 升级为 2：在锁与事务中校验原 schema 和全部原始记录，再迁移；保留原 payload、序号、时间及服务器身份。旧版程序无法写入新 schema，降级不承诺兼容。
- 查询与导出新增档案、主机、端口、用户名过滤；筛选与快照分页语义一致，导出覆盖筛选的全部记录，不只当前页。
- JSON 导出版本为 2，CSV 末尾增加 profile_id。

## 本地验证

使用隔离源码快照，只应用本阶段变更后运行：

- `cargo test -p xyz-core`：187 单元测试、15 模型集成、19 SSH 回环、8 Agent 集成通过；3 环境隔离单元测试和 2 OpenSSH 测试为显式忽略，未声称执行。
- 其中日志存储测试 22 项通过，包含 v1 数据迁移保留、档案跨目标历史筛选与全部匹配导出、payload/列关联不一致拒绝。
- `cargo fmt --all -- --check` 通过。

本阶段未进行 Windows 原生验收或新版 UI 验收。实时 SSH 会话绑定档案、当前 Shell 集成、界面入口及后续升级安装验收仍在开发，不应将此准备阶段当作最终功能验收。
