# v0.1.2 自动执行实现边界

## 已实现的推进条件

终端任务启动前必须存在当前连接的受支持 Shell 集成就绪状态；SSH 已连接、用户开始任务、日志开关和文字提示符均不能代替它。初次接入使用终端工具栏的单独当前空闲 Bash 确认。

每个命令保留任务、运行、连接代次、命令全文摘要、显示确认和一次性批准；同时保存准备命令时的 Shell 实例、序号和状态修订。真正写入前再核对相同绑定。普通命令无需风险批准，但准确动作必须先提交到已挂载、可见应用的内存任务视图；切换聊天或打开非模态设置不暂停普通步骤。整个应用不可见或卸载时不再确认新动作。此内存状态不代表同意写入日志。危险／未知批准动作仍要求准确卡片实际显示。危险命令批准只能用于当前这一动作，不能复用或授权后续动作。

命令预览的摘要同时绑定原命令与确定性的“# xyz-action:动作ID”惰性注释和 Enter。注释在卡片及可见 PTY 中披露，不执行额外命令；重复命令在默认 HISTCONTROL=ignoredups 下因此仍能准确关联。

本地写入收据只进入“等待命令返回与 Shell 就绪”。匹配 begin/end 记录前台返回及退出码，只有另一个匹配的 ready 事件允许启动下一轮模型分析。退出码零不证明业务目标成功，也不表示后台任务完成。执行进度与日志保存完全分离。

正常流程最多 16 轮。五分钟内缺少完整完成与就绪证据会暂停到人工处理，此超时不推断成功、不生成退出码，也不重发。用户停止 AI 不发送 Ctrl+C；已发送命令不可撤回。未开始写入且本机明确确认 not_sent 的排队取消可释放原就绪预留，已开始或结果不明的命令不可以。

## 本机风险语法

这是限定范围的解析器，不是完整 Bash 解释器，也不是安全沙箱。

- 只接受单行、一个字面命令；支持空格分词和无展开的单／双引号
- 单引号内的字符作为字面值；双引号内的变量、命令替换、反斜杠和历史展开不受支持；行首空白会触发某些 Bash 历史忽略规则，因此不进入自动执行
- 管道、复合操作符、重定向、变量赋值／展开、命令替换、未引用通配符、注释及脚本解释器归为未知风险
- 当前 ready 快照中出现的别名／函数命令名归为未知风险；保留用户原有定义，不禁用它们。对已识别工具可以明确使用 command ls 等 builtin 绕过形式；只有 command 本身未被遮蔽时才使用对应普通规则。宿主不静默改写用户审阅的命令
- 绝对／相对可执行文件路径、自定义程序、嵌套解释器、交互式身份切换和长期交互流程需手动处理
- 模型不能提供风险类别、批准或退出码；只有本机策略及相应 lifecycle 证据产生这些字段

普通规则覆盖以下命令的明确参数子集（完整参数表在 risk.rs）：pwd、whoami、id、uname、hostname 查询、uptime、date 查询、ls、df、du、free、cat、head、tail（不含 follow）、wc、stat、grep、find 的路径／名称／类型／深度查询，显式路径 cd，以及 echo／printf 字面输出、ps／ss 查询、带 --no-pager 的 systemctl 查询和 journalctl 有限查询。支持常见短选项、少量明确长选项和带空格的引用路径；不继续依赖 12 条精确字符串。

已识别删除、覆盖、权限变化、服务管理、数据传输等命令标为危险，须单次批准。例如 rm、mv、cp、chmod、systemctl、curl。保守规则也把 mkdir、touch 等写操作纳入批准。sudo 的字面已识别子命令（例如 sudo systemctl restart nginx，以及 -n、-u、-g 等限定选项）也必须逐次批准；sudo -s、脚本和嵌套解释器仍需手动处理。若 sudo 等待密码，不能视为完成，用户需手动处理或在暂停后使用既有单次秘密输入流程。find -delete、date 设置时间和 hostname 更改名称不会误标普通。

普通程序的部分未支持参数保留“未知风险”，可在完整核实后进行一次批准；批准不会将其改成普通。不能建立单个顶层行为边界的语法、别名／函数、脚本、find 执行子程序、tail follow 等保持手动处理，不用批准按钮假装支持。

假定远端工具实现符合对应常用程序语义。远端二进制、PATH、Shell 配置及生命周期元数据不构成可信安全边界。nonce／序号用于关联，不能认证远端。并发人工输入由用户自行避免；本版不增加键盘接管锁。

## 失效与恢复

旧 Shell 修订、连接变化、begin/end/ready 丢失或乱序、已知元数据缺口都会阻止继续。普通输出中的“成功／已就绪”不生效。日志故障不自动关闭执行跟踪；跟踪故障则暂停自动派发。旧日志、数据库和模型文字不能恢复授权。

恢复确认仅说明用户核实了当前终端，不把上一条未知命令标成成功。继续执行仍须当前 Shell 集成重新达到受支持就绪状态；无法安全恢复时保留手动终端或重新连接。恢复不会自动重发旧动作。

## 验证记录

- Rust gate 单测：单一写入者、完整显示、批准绑定／一次性、过期与连接失效、取消、独立完成后准备下一动作
- 风险单测：常见带参数普通命令、危险行为、动态语法、别名／函数、脚本和未知参数
- loopback SSH + SSE：连续普通步骤、危险步骤批准、独立 ready 前不推进、失序标记／断连不继续、不重发、背压下取消、秘密输入既有边界
- React：正常等待状态没有逐命令就绪按钮，前台退出码与业务成功分离，未知动作手动提示，停止／断连／显示确认流程

真实 Bash PTY hooks、OpenSSH 与桌面打包验证由对应集成验收记录单独说明；这些 loopback 测试不会声称覆盖所有远端 Shell 或提示符插件。
