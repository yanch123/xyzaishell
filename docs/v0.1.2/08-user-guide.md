# 08 — v0.1.2 使用指南

本文对应 v0.1.2。下载安装包及验证范围请查看 [GitHub Releases](https://github.com/yanch123/xyzaishell/releases) 的实际版本；v0.1.1 用户可参考[旧版指南](../v0.1.1/05-user-guide.md)。建议先在测试服务器上使用。

## 1. 连接服务器

点击工具栏“新建连接”，填写主机、端口、用户名和密码，或选择本机私钥文件。

- 临时连接：不勾选“保存连接”，凭据只用于本次认证。
- 保存资料：勾选“保存连接”并填写名称。以后缺少密码时，在连接管理中按提示补输。
- 记住凭据：在保存连接的基础上明确勾选“记住密码”或“记住私钥口令”。Windows 使用当前用户系统保护，Linux 需要可用、已解锁的 Secret Service；失败不会自动改存明文。

点击“连接服务器”后，需保存的资料先保存成功，再发起连接；网络失败不会撤销已经保存的资料。“仅保存连接”不连接服务器。首次连接或主机密钥变化时，先通过可信渠道核对指纹。

“连接管理”可选择、编辑、重命名、删除连接或查看操作日志。编辑后保存不自动连接；已有秘密不会回填。修改认证目标需要重新核对凭据。删除资料不会删除私钥文件、主机信任、历史或日志，也不会断开现有连接；旧版备份或系统存储中的孤立凭据条目可能保留。

一个窗口对应一个独立进程和一条 SSH 会话。已有连接时，新建或连接另一目标默认打开独立进程窗口，原窗口继续工作。只有明确选择“在当前窗口切换”才会请求停止 AI、断开旧连接；切换失败不会自动恢复旧会话。“重新连接”会重新核对保存资料，必要时询问凭据。

## 2. 在设置中填写模型

打开“设置 → 模型”，填写 Base URL、API Key 和模型名：

1. Base URL 是 API 根地址，不要填写完整 `/chat/completions` 路径。
2. “保存”只写入本机配置，不发送请求；“保存并测试”先保存，再显示测试目标和发送范围供确认。
3. 测试只发送固定的“Reply with OK.”，不携带聊天或终端内容。通过仅说明已测流式聊天可用，不证明工具调用兼容。

已有 Key 显示“已配置，留空保持不变”。清除使用单独按钮；更换服务地址不能默认复用旧 Key。保存冲突或结果不确定时，先重新读取并核对，不要反复点击。保存后测试失败不撤销保存。

设置不会锁住终端。模型未配置也不影响手动 SSH。API Key 仍以明文保存在受限权限的本机 `model.toml`，并未进入 SSH 的系统凭据存储；不要放入 Git、同步盘或共享目录。配置路径、权限、环境变量覆盖和高级字段说明位于“高级配置与安全说明”。

## 3. 启用命令状态识别

手动 SSH 和普通文字聊天不需要此功能。需要 AI 连续操作终端时：

1. 先完成 SSH 登录，确认当前没有命令运行，并已显示 Bash 命令提示符；不要在密码提示、编辑器或其他前台程序里启用。
2. 点击工具栏“命令状态识别”，阅读范围并勾选确认，再点击“启用命令识别”。
3. 等待显示“命令识别已就绪”。启用脚本会经过当前可见终端，只在本次连接生效，不安装软件、不改写启动文件、不新建干净子 Shell，也不自动开启日志。

当前支持交互 **Bash 5.1 / 5.2** 的受限配置：支持常见 Ubuntu 提示符、`HISTCONTROL=ignoreboth` 和关闭 `lithist`，保留并核对现有 `PS0`、字符串或数组 `PROMPT_COMMAND`。需开启 `history`、`cmdhist`、`promptvars`、`interactive_comments`，并保持 `HISTIGNORE` 为空及默认 `histchars`；提示符中的命令替换或不安全展开、除 `EXIT` 外的显式 trap（包括 `WINCH` / `ALRM` 异步信号及 `DEBUG` / `RETURN` / `ERR` / `CHLD`），以及 `functrace` / `extdebug` / `errexit` 等配置不受支持。支持版本不代表任意启动脚本都兼容。

不支持、握手失败或状态未知时不会盲目重装；手动终端仍可使用。核对实际前台状态，必要时重新连接后再明确启用。远端可以修改环境或伪造事件，这不是安全沙箱或不可篡改审计。

## 4. 让 AI 执行任务

“文字聊天”只用于讨论；在“执行终端任务”输入任务后，点击“核对并开始执行”，核对模型接收方、当前服务器和数据范围，再明确授权。当前会话已有有效就绪证据时，不再重复要求每个任务勾选空闲提示符确认。

- **普通命令**：宿主识别的有限字面检查、目录导航及支持的参数，可以在显示后自动发送；收到匹配的前台返回和就绪事件后继续。不是任意命令都自动执行。
- **危险命令**：查看完整命令、目标和影响，单次批准只适用于这一动作及对应连接状态。
- **未知或不支持的命令、结果未知**：暂停自动推进，按卡片要求核对；不能把关闭提示、终端静默或过去的批准当作成功和新授权。

前台返回不等于后台程序或业务目标已经完成。多个聊天共享同一个 PTY，一次只有一个 AI 任务写入；请避免同时手动输入。“停止 AI”不撤回已发送命令，也不自动发送 Ctrl+C。需要中断远端程序时使用终端的独立 Ctrl+C 操作。

AI 面板持续显示当前服务器及聊天来源。连接不同目标会创建新聊天；旧目标聊天及恢复的历史只供阅读，不迁移现场上下文或恢复批准。重连同一目标可保留文本，但需重新建立命令状态识别。

## 5. 查看、筛选和导出操作日志

日志独立于模型，默认关闭；命令可能含密码、令牌或业务信息，必须明确同意本机明文保存。开始新记录前，必须先通过工具栏“命令状态识别”启用识别并等待“命令识别已就绪”，再回到日志面板勾选明文保存同意。日志面板不会自动启用或重装命令识别。暂停日志只停止记录，不关闭正常工作的执行状态识别，不补录暂停期间的数据。

入口决定初始范围：

- “当前终端日志”：当前会话。
- “连接管理 → 操作日志”：所选连接的历史，包括离线记录。
- “查看 → 操作日志”：全部记录，可按原主机、账号和关键词筛选。

日志面板不锁住终端。每条记录保留原主机、端口、账号和会话；连接更名不会重写旧记录，旧数据缺少档案 ID 时显示“档案关联未知”。浏览和导出离线记录不连接服务器，也不自动开始记录。

点击“导出 JSON”或“导出 CSV”导出当前筛选快照内的全部匹配记录，不限当前页。修改筛选后先点击“筛选 / 刷新”。文件写入本机私有目录且不覆盖旧文件，结果显示可复制的完整路径。CSV 对可能触发表格公式的文本作安全处理；规范文本请选择 JSON。日志默认不保存终端输出，不自动发送给模型，也不是脚本。

## 6. 提示、历史和故障

底部消息面板汇总连接、配置等操作结果，不替代命令日志或聊天历史。待决定事项仍需回到原入口处理，消息已读或关闭不表示同意。

聊天明文历史在“设置 → 历史记录”单独开启。恢复仅恢复文本，不重连、不启动执行、不重放命令或批准。任务需要的密码或令牌请使用[任务秘密文件流程](../v0.1/11-user-guide.md#5-任务中的密码和令牌)，不要粘贴到聊天中。

遇到错误先保留脱敏错误码和界面状态，检查实际终端；保存结果或命令结果不明确时不盲目重试。报告问题时提供应用版本、系统版本和复现步骤，不上传真实 Key、密码、私钥或含秘密的截图。
