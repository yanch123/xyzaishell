# 05 安全与风险边界

版本：design-v0.1。本文规定设计期的安全边界，不表示实现已经具备这些保护，也不保证任意远端程序或任意模型的安全性。

## 1 信任与职责

可信决策来源是用户明确操作及本机执行策略。主模型输出、未来决策模型的判断、远端终端输出、文件内容、错误提示和终端标题均不能授予权限。

模型提出动作，Rust 执行控制层验证动作、状态及授权后才允许发送。模型不持有 SSH 写通道、通用本机文件读取权限或秘密查询工具。前端只获得当前窗口必要的 IPC 能力；模型文本和远端数据不得生成可直接执行的前端脚本。

## 2 明确接受的使用限制

用户自行避免手动输入与 AI 输入冲突。本产品不根据键盘活动自动暂停、恢复或撤回 AI 操作，不承诺人工输入优先。正常的底层字节顺序和单个 AI 任务所有权仍须维护，但不构成用户与 AI 之间的仲裁。

已经发送的字符不能撤回。用户改变目录、用户身份、环境变量或前台程序后，模型先前的判断可能失效。多个对话仅在聊天和配置上独立，实际共享一个远端 Shell；不能将任务隔离描述为远端进程或权限隔离。

手动输入不经过 AI 命令的审批工作流。软件仍按正常 SSH 客户端转发用户明确输入；不能将该通道暴露为模型绕过审批的工具。

## 3 高风险授权

### 3.1 基础策略

首版保留基本风险检查：删除、覆盖、权限和账号修改、提权、服务中断、数据外传等已识别风险需要授权。脚本、解释器、别名、复合命令或交互程序中的输入可能隐藏真实作用；无法可靠确定时返回待确认，不把未命中关键词当作安全。

不承诺静态规则能识别所有副作用，也不把只读命令名称当成服务端只读保证。应使用权限受限的远端账号；客户端不会提供远端操作系统级沙箱。

### 3.2 授权内容与有效性

授权界面显示服务器身份、任务、准确命令模板、已知作用范围、秘密引用名称及脱敏的执行预览。秘密实际值不在授权文本中展开。授权绑定不可变动作标识、命令内容、连接代次、凭据版本及可获得的执行上下文，且只能消费一次。

改变命令、重新连接、切换执行任务／写入所有者或修改相关配置使旧授权失效。对于未能观测到的用户手动环境变化，软件不能保证自动检测；授权提示需披露命令将作用于当前实际终端状态，用户负责避免期间干预。已知状态变化必须重新检查。

模型不能调用“批准自身动作”。拒绝后不得通过换措辞、另一个工具或原始按键自动绕过。对 `y` 等交互确认输入，若由 AI 提出，同样按动作处理；状态未知时不自动发送。

### 3.3 暂停与停止

“停止 AI”阻止后续自动动作，不等于终止正在运行的远端程序。中断命令是单独、显式的用户操作；Ctrl+C 的结果依赖远端终端和程序，不保证取消成功，更不提供回滚。

## 4 配置和凭据

模型设置、SSH 连接资料、单个任务凭据必须分开。模型 API Key 只作为访问选定模型服务的认证信息；SSH 凭据仅用于对应连接。任务秘密只能被所属任务通过明确引用使用，模型只看到键名及是否配置。

SSH 凭据按平台适配：Windows 拟用 DPAPI CurrentUser 保存密文；Linux 拟用 Secret Service 兼容 keyring，配置只保存应用生成的、绑定连接与用途的不透明引用。私钥仅保存路径。不能把某个平台的保护属性宣称为两个平台完全等同的保证，也不能假设 Linux 桌面都有可用安全存储。

Linux 服务缺失、无可用 D-Bus 会话、keyring 锁定或拒绝解锁时，持久保存／读取必须失败且给出明确提示，禁止明文落盘回退。可由用户显式选仅本次进程内存保留并在专用认证 UI 手工输入；关闭后需重填。禁止将 SSH 凭据转存模型文件、任务文件、日志或命令行作为变通。安全存储故障不会降低主机验证／动作授权要求。

用户编辑的模型和任务配置仍可能含明文秘密，应限制本机访问、避免同步或不可信备份；这不是加密保险箱。Windows 使用受限 ACL，Linux 应用目录／临时目录拟为 `0700`，秘密文件／临时文件为 `0600`；已有位置先校验 UID、权限和链接，不擅自扩大访问。系统管理员、已被控制的同用户进程、内存转储及远端程序仍是剩余风险。

跨平台复制配置不能迁移 DPAPI 解密能力或 Linux keyring 条目。本地绝对路径及引用需重新校验，认证材料重新输入，不明文导出。keyring 与配置文件并非同一事务，提交失败／未知时不得先删旧凭据或宣称已回滚。具体字段、保存顺序和迁移以[配置规范](04-configuration.md)为准。

禁止将秘密当作任意 Shell 源码直接替换后执行。真实值中的引号、换行、美元符号、控制字符等必须按已支持的参数位置正确编码；无法确定语境时转由用户处理，不使用 eval。任意密码提示的自动填充不是首版的通用能力承诺。

即便秘密不进入模型，发到远端后仍可能出现在进程参数、Shell 历史、跟踪输出、应用日志和服务器会话录制中。产品不能保证这些外部渠道不泄露。

## 5 模型上下文与数据发送

建议默认仅使用当前任务关联的、经过过滤且有长度上限的命令与输出，不自动上传整个终端历史。此数据策略在首次启用 AI 时应向用户展示服务地址和发送范围并取得确认；当前文档不代表用户已经授权向任何真实服务传输数据。

本机先进行已知秘密过滤，再发送给任何模型。过滤应跨流式分块匹配，并覆盖模型上下文、界面脱敏视图及持久化日志。未知秘密、编码后的变体、服务端转换输出可能无法识别，不能宣称完美脱敏。其他对话观察共享输出时也不能绕过过滤。此处界面脱敏视图指命令卡片和聊天，不承诺原始终端回显全面遮罩。

不将真实密钥返回前端以便调试，不在错误中回显 Authorization。更改模型服务目标时明确提示数据接收方变化；进行中的请求固定使用启动时配置快照，不静默迁移历史上下文。远程模型端点默认要求 HTTPS；本机开发端点例外需明示。

## 6 未知状态与断线

普通 SSH PTY 不提供任意交互命令的可靠结束证明。首版不实现复杂终端判断，只维护已获得证据和明确的未知状态；未知时暂停对应 AI 步骤，提示用户处理或确认特定动作。用户确认不是虚构的退出码，也不是对后续任意按键的无限授权。

断线或崩溃发生在发送中、运行中或结果未确认时，记录“结果未知”。不得自动重发该命令。重连生成新的会话代次并使旧审批失效，先核对实际状态。聊天持久化、Rig 状态恢复都不能恢复远端 Shell 状态或保证恰好执行一次。

## 7 可选决策模型边界

首版仅预留接口，不调用 Jev，不附带 Jev 密钥配置要求。未来模型可返回风险或状态评估，但不能批准动作、获取秘密、直接控制终端或将未知执行结果当成事实。

未来服务超时、输出格式错误、不确定或未启用时，维持基础策略，必要时询问用户，不降低授权要求。Jev 官方明确披露对抗性输入可能影响判断，不能作为唯一安全边界。接入新的托管服务前需要说明上下文将发送至另一个接收方。

## 8 前端与 SSH 基础安全

- 打包可信本地前端，限制 CSP 和 Tauri IPC，模型及终端衍生文本按不可信内容展示。
- 明确限制链接协议、剪贴板控制序列及自定义转义序列处理，不让远端输出直接调用本机权限。
- 校验 SSH 主机密钥；首次连接展示指纹确认，已保存密钥改变时阻断自动连接并提供人工核验路径，不能默认接受任意密钥。
- 配置文件按平台执行受限临时文件、稳定锁、原子替换与同步／版本检查；保存结果未知时重读核对，不能伪称没修改。外部编辑器不遵循锁的竞态需披露；任务凭据不共享到其他任务。
- Linux POSIX 路径不能仅凭字符串形式判断为本地安全文件；检查普通文件、归属、权限、符号链接与目标文件系统。Windows 同样检查 ACL 和重解析点。两平台均不暴露本地 shell 工具。
- 记录最小化审计信息，设置输出和保留期限上限，避免无限保存含业务内容的历史。

## 9 首版不承诺

任意 Shell 自动化、无误风险分类、零提示注入、绝对防泄密、自动命令回滚、断线恰好一次执行、手动和 AI 同时输入互不干扰，均不属于首版保证。
