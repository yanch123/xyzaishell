### 开发命令

需要 `rust-toolchain.toml` 所列 Rust 工具链、Node.js 22.12+ 与 npm，以及 [Tauri 平台开发依赖](https://v2.tauri.app/start/prerequisites/)。

npm ci
npm test
npm run build
cargo test -p xyz-core --locked

## M3 终端 Agent 与执行授权（2026-10-14，UTC+8）

每次终端任务明确确认模型接收方、终端输出发送范围和 shell 就绪；多聊天只允许一个 AI 写入者。命令写入不等于执行成功；无法判定完成时进入未知状态，要求用户明确继续。取消不隐式发送 Ctrl+C、不自动重放；队列中未开始的动作与已经开始写入的动作分别处理。Jev 仅保留返回 Unknown 的扩展接口。

工具调用必须在完整模型流结束并通过严格 JSON／工具批次校验后才能形成动作。终端观察有界、过滤控制序列，并按运行保留脱敏规则，即使 SSH 重连也不丢失旧任务的秘密过滤。纯对话同步修复分块回显 API Key 的风险，保留正常换行和制表符。脱敏是降低风险，不保证识别所有未知秘密或变形编码；不得将不应披露的终端内容交给模型。

## M4 凭据、任务秘密与保守历史恢复（2026-10-14）

已接入保存的 SSH 档案、Windows DPAPI／Linux Secret Service、明确的整份档案会话内存模式、持久主机信任，以及 Windows 安全私钥读取。允许先保存无凭据的目标档案，认证仍要求凭据。会话凭据更新同时校验配置修订，并与其他实例的档案修改持有相同稳定锁；不会将新输入静默用于已经改变的目标。

任务秘密由独立本机文件提供，模型只请求字段元数据。用户核对当前远端程序正在等待秘密后，再通过单次显示／授权门输入单行值；不提供任意 Shell 秘密插值。文件验证在阻塞池中执行，最终 SSH actor 边界继续检查任务、连接、授权、有效期与秘密快照代次。编辑／重载、取消及排队期间变化均有拒绝与释放写入权回归测试。

聊天历史需每次进程明确选择，默认不创建数据库。SQLite 只保存有界、已知秘密脱敏后的文字和不可执行摘要；不保存原始终端或可重放授权。恢复保持稳定聊天／任务标识，但不恢复活动运行、模型网络请求或 SSH。跨实例修订冲突、损坏、容量限制和保存失败可见；终端最终摘要只写入一次并保留结果未知语义。可显式逐条移除存档，警告逻辑删除不可恢复且不保证物理擦除；移除后不自动重新保存同一记录。

父级最终聚合检查：185 项 Rust 测试通过（143 单元、15 模型 HTTP、19 SSH、8 终端 Agent），4 项平台／服务／OpenSSH 夹具测试在普通本地运行中明确跳过；严格 Clippy、格式、99 项前端测试、TypeScript、生产构建与 diff 检查通过。独立集成审查已关闭秘密请求用途漏脱敏、旧凭据修订、历史启用竞态、保存标题重新脱敏、UI 迟到恢复及无效草稿误锁定等发现。
