# 11 使用指南

版本：v0.1 开发阶段。本文说明当前实现的操作流程；安装包与平台验证状态以 [09 开发记录](09-development.md) 和对应发布说明为准。开发阶段的 CI 产物不是正式 Release。

## 1. 首次启动

程序左侧是 SSH 终端，右侧是 AI 区域。一个窗口连接一台服务器；需要同时操作多台服务器时，启动多个应用实例。多个 AI 对话共享该窗口的远端环境，但同一时间只有一个 AI 任务可以写入终端。

Windows 使用 NSIS 安装包，依赖 Microsoft WebView2。Linux 主包为 DEB，目标为 Ubuntu 22.04／24.04 x64，依赖系统 WebKitGTK／GTK。实际支持与尚未验证的桌面组合见发布说明。仅打开前端网页预览不能建立 SSH 连接或执行本机命令。

## 2. 配置模型

1. 打开设置，查看应用选定的模型配置文件路径。
2. 将 [模型示例](../../config/examples/model.example.toml) 复制到该本机路径，用编辑器填写 `model.base_url`、`model.api_key` 和 `model.name`。Base URL 是 API 根地址，通常以 `/v1` 结尾，不要追加 `/chat/completions`。
3. 文件中还保留 schema、协议和请求限制字段。占位地址、占位 Key 和占位模型名不能直接使用。
4. 文件保存在私有本机目录，不放入 Git、同步盘或共享目录。API Key 在此 TOML 文件中是明文；Linux 私有目录使用 `0700`、文件使用 `0600`。Windows 文件须符合应用的当前用户／系统管理员权限检查。
5. 点击“重新加载模型配置”，核对实际模型接收方。发送前明确同意数据发送范围。
6. “测试连接”发送一个独立的最小文字请求，只验证聊天流式响应，不代表工具调用兼容性已经通过。

默认配置根目录：Windows 为 `%APPDATA%\xyzaishell`，Linux 为 `$XDG_CONFIG_HOME/xyzaishell` 或 `$HOME/.config/xyzaishell`。如需自定义模型文件，给应用启动环境设置 `XYZAI_MODEL_CONFIG`，值为完整绝对路径。修改这个路径变量后重启应用；重新加载只读取本次进程选定的路径。应用不会使用 `OPENAI_API_KEY` 等变量覆盖文件中的设置。

不要把 Key、SSH 密码、私钥或整份配置粘贴到 AI 对话。仅允许 HTTPS 模型地址；本机回环 HTTP 必须在配置中显式启用，主要用于测试。

## 3. 连接 SSH

可以使用一次性连接，也可以创建保存的 SSH 档案。填写主机、端口、用户名，选择密码或本机私钥绝对路径；加密私钥需要口令。`.ppk` 等格式或其他认证方式未验证时，不应假设兼容。

首次连接会显示主机密钥指纹。应通过可信渠道核对，再确认信任。指纹变化不能因为“连接失败”就直接接受，应先检查服务器是否确实换了密钥。

保存档案与保存凭据是不同操作：

- 档案保存非秘密连接信息。
- 明确保存凭据时，Windows 使用当前用户 DPAPI；Linux 使用 Secret Service 兼容安全存储。
- Linux 安全存储不可用／锁定时，不会自动把秘密写入明文文件。可在系统中修复安全存储，或明确将整份档案配置切换为会话内存模式。
- 会话内存模式退出后需重新填写凭据。切换影响所有档案，会移除配置中的持久凭据引用；不会默认删除系统安全存储的旧条目。当前界面不提供切回原持久模式的迁移操作，切换前请确认。
- 配置保存结果不确定或发现其他实例修改时，先重新读取状态，不要反复点击保存覆盖。

私钥文件只由本机 SSH 认证代码读取，不发送给模型。软件不提供 SFTP、文件上传下载或本机 PowerShell／WSL。

## 4. AI 操作终端

普通文字聊天不会自动写入终端。需要实际操作时，在对应聊天中明确启动终端任务，并确认接收方、终端输出发送范围和当前 Shell 就绪。

程序先展示准确的命令卡片。少量精确匹配的常规命令可自动执行；其余命令要求逐条批准。审批只针对当前任务、当前连接、当前不可变动作，不能用于修改后的命令或重连后的新连接。

命令经同一个可见 SSH PTY 输入，不切换到隐藏的独立执行通道。写入成功不等于命令运行成功；当前版本无法可靠判断完成时，会等待你查看终端并明确继续，不会编造退出码。

手动输入始终可用。你需要自行避免在 AI 输入时同时打字，特别是远端程序正在读取密码、编辑器或不完整命令时。停止 AI 只阻止后续规划和写入，不代表撤销已经发送的命令，也不自动发送 Ctrl+C。

## 5. 任务中的密码和令牌

模型需要任务凭据时，只提出字段名和用途。点击“准备本机秘密文件”，在界面显示的本地任务文件中填写对应值，再点击“重新加载已填写状态”。每个 AI 任务使用独立文件；模型只得到字段是否已填写等元数据，不得到值或本机文件路径。

需要发送到远端时：

1. 确认左侧终端正在等待正确程序的秘密输入，而不是普通 Shell 命令行。
2. 选择已填写的字段，说明用途，核对目标并确认远端回显风险。
3. 点击“核对本次秘密输入动作”。
4. 核对秘密输入卡片，再批准这一次输入。

适配器只支持单行秘密输入并追加一次 Enter，不把秘密拼入任意 Shell 命令。文件被修改、重新加载、连接改变或动作取消后，旧动作失效，必须重新核对。不要在聊天或用途字段中填写秘密值。

任务文件是受限权限的本机明文文件，不是保险库。编辑器备份、同步软件和远端程序可能记录值。已知值脱敏用于降低风险，不能保证识别未知、编码或变形后的秘密。远端终端自身的原始回显仍可能显示秘密。

## 6. 保存和恢复历史

本机聊天历史默认关闭，每次启动需明确选择启用。启用后保存脱敏文字到本机明文 SQLite；请勿把敏感资料当作普通聊天保存。关闭只停止新增保存，不删除已有文件，也不保证清除磁盘历史副本。需要移除某条存档时，核对记录名称与标识并单独确认；该逻辑删除不可恢复，也不保证物理擦除。

恢复只读取历史文字；不会恢复 SSH 连接、启动模型、批准动作或重发命令。历史中的终端摘要不是当前远端状态证明，未知结果仍需人工核实。不会保存原始终端输出或可重放的授权。

状态目录与秘密配置分开：Windows 为 `%LOCALAPPDATA%\xyzaishell\state`，Linux 为 `$XDG_STATE_HOME/xyzaishell` 或 `$HOME/.local/state/xyzaishell`。多实例发生保存冲突或文件损坏时，应用应报告错误，不自动清空历史。

## 7. 常见情况

- **模型配置无法读取**：核对应用显示的路径、TOML 字段和文件权限，不要把 Key 发到聊天里排查。
- **文字聊天可用、工具执行不可用**：服务可能不支持所需的流式工具调用；不要把模型自由文本当作已执行命令。
- **另一个任务正在操作终端**：先停止或完成该任务。新任务不会自动夺取写入权。
- **断线后结果未知**：检查远端实际状态，再决定后续操作。不要盲目重发有副作用的命令。
- **安全存储不可用**：修复系统安全存储，或明确选择会话内存模式；不提供明文自动回退。
- **界面提示保存结果不确定**：重新读取后核对，不自动重试写入。

报告问题时提供应用版本、系统版本、脱敏错误码和复现步骤。不要上传真实 Key、密码、私钥、任务秘密文件或包含秘密的终端截图。
