## 实现边界

- 上下文的宿主事实仅记录匹配的前台返回；输出解读和步骤状态属于模型报告，不能作为独立业务成功证明或执行许可。
- 命令关联的输出片段可能混入手动／后台输出，仍为不可信数据；截图和引用不能消除这一限制。
- 上下文 JSON 上限 32 KiB；证据／宿主事实最多 16 项，解读／假设各 8 项，步骤 12 项，每项引用最多 4 个。命令摘录 256 字节、输出摘录 512 字节；模型提示 60 KiB，历史上下文文字 4 KiB。
- 摘要更新不触发 SSH、不完成任务。规划与命令同受 16 轮上限；达到上限明确报告 TASK_ROUND_LIMIT、释放写入权，不重发命令。末轮完成输出保留在快照中。
- 选段最多 8 KiB / 200 行，明确显示裁剪／编辑状态。末尾保持为选段原文边界，让后端前缀安全脱敏可识别在裁剪处结束的已知秘密。
- 只过滤已知秘密及规则覆盖的变体，不保证回溯识别此前未知、任意编码或被模型改写进其他文本中的碎片。
- 字号 10–28 px、回滚 500–20000 行；localStorage 只保存有版本的显示偏好，不保存选段／终端内容。粘贴最多 16 KiB，明确预览确认，不额外追加 Enter，不允许危险控制字符。
- 工具能力检查仅调用固定模拟工具声明，永不派发该工具或连接 SSH。supported 仅指本次响应适配当前流式工具协议；网络、认证、超时、拒绝等使用 inconclusive，不假称永久不支持。
- 升级脚本已从固定 v0.1.2 安装包验证升级到 v0.1.3，使用真实发布产物哈希及现代 UI，不再错误要求同 schema 升级产生旧版迁移备份。辅助校验通过不等于原生升级已验收。

## 审查修复与回归

独立只读审查发现并复核修复了以下问题：

1. 晚加载秘密命中模型 ID 后，重复脱敏可能膨胀超过 32 KiB。现在移除冲突的模型条目、标记裁剪，并在证据耗尽后仍执行总预算约束；128 次重复脱敏回归通过。
2. 历史命令在当前共享脱敏之前裁剪，可能泄露已知秘密前缀。现在同时使用运行与当前共享过滤器，在裁剪／JSON 嵌入之前逐字段过滤；实际边界回归通过。
3. 选段裁剪后追加结束标记，使后端无法把截断的秘密前缀识别为末尾前缀。现在选段是精确消息末尾；8 KiB 与 200 行边界测试及真实 TaskManager→模拟供应商请求断言通过，存储聊天亦不包含该前缀。
4. 第 16 轮完成时没有下一轮，末条命令输出未保留且状态误显示完成。现在保留最后观察，并在三个轮数上限路径明确失败与释放所有权；真实 SSE／SSH 测试核对恰好 16 次请求、无额外请求或重放。

审查范围内未留下已确认阻塞项；这不是所有输入／平台均无缺陷的保证。
