# 05 — v0.1.3 新功能使用说明

本文对应 v0.1.3 开发功能；是否已有可下载版本，以 [Releases](https://github.com/yanch123/xyzaishell/releases) 为准。

## 1. 查看任务的事实与剩余步骤

在右侧选择“执行终端任务”，启动任务后展开“已确认事实 / 剩余步骤”。

- “已确认事实”中的排查结论由模型根据命令输出整理；可展开关联命令查看保留的输出片段。它不是独立核验结果。
- “待验证推测”用于尚未证实的判断。
- “剩余步骤”显示待处理、进行中、受阻或模型标记的完成状态。
- 程序识别的前台返回与退出码单独显示。退出码为 0 不代表业务目标一定成功。

摘要会供本任务后续分析使用；不在不同服务器或新任务之间自动继承。输出和摘要都有容量限制，看到裁剪或缺口提示时应核对左侧终端。达到任务轮数上限后需检查进展，不会自动重发命令。

## 2. 把选中的终端内容交给 AI 分析

1. 在左侧终端选中需要解释的内容，点击“选区交给 AI…”。
2. 在右侧文字聊天中核对固定来源、模型接收方和选区预览；可删除敏感内容或移除附件。
3. 勾选本次发送确认，再点击聊天发送按钮。可先输入具体问题。

选段上限为 8 KiB / 200 行，截取会明确标记。消息也会包含当前聊天已保留的历史。该流程只进行文字分析，不启动终端任务或执行选区中的命令。

改变选区、切换聊天、重连或修改模型后须重新核对。来源不匹配时，请在当前服务器的新聊天中重新选择。首次确认模型接收方后，也需返回附件再次核对再发送。已知秘密会按现有规则过滤，但不能保证识别未知、变形或编码的秘密，请自行审阅。

## 3. 搜索、复制粘贴和显示设置

- 点击终端“搜索”，或按 Ctrl+Shift+F；输入文字后用上一个／下一个按钮定位，Esc 关闭。搜索范围是当前保留的终端回滚内容，不是远端文件。
- Ctrl+F 和 Ctrl+C 保留 Shell 原有行为。复制选区使用明确的按钮或 Ctrl+Shift+C；粘贴使用按钮或 Ctrl+Shift+V。
- 粘贴先预览再确认；换行可能执行远端命令，确认前必须核对内容和目标。应用不会额外追加 Enter，不允许不安全控制字符混入粘贴。
- 打开“设置 → 终端”，调整字体大小与回滚行数。缩小回滚行数可能丢弃更早的屏幕显示，不会删除服务器文件或操作日志。

剪贴板访问失败时会提示错误；不要把未完成的粘贴视为成功。

## 4. 模型与 Shell 能力检查

在“设置 → 模型”保存配置后，可分别检查文字聊天连接和终端任务所需的工具调用能力。每次测试都需核对接收方；工具测试只发送固定的模拟请求，不包含终端内容，不连接 SSH，也不执行命令。

- 支持：本次返回符合当前适配器要求。
- 不兼容：本次完整响应不符合需要的工具格式。
- 无法确定：可能是网络、认证、超时、拒绝调用等原因；需按提示处理后自行重新测试。

测试通过不保证所有复杂任务都会成功。终端工具栏的“命令状态识别”用于查看当前 Bash 集成状态；不兼容时会说明具体条件。应用不会为通过检查而自动改动远端 Shell 配置，手动终端仍可使用。
