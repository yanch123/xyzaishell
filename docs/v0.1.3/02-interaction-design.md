# 02 — v0.1.3 交互设计

状态：交互基线；实现和验证进展见开发记录。本版延续左终端、右 AI 的窗口结构，新增操作不能使用户失去对当前服务器、发送内容和执行状态的判断。

## 1. 任务摘要的阅读与更新

在“执行终端任务”内，为当前任务提供“本任务上下文”区域。先展示简短摘要和剩余步骤，展开后可查看事实、模型解读、假设与证据。无需切换窗口或离开终端。

### 1.1 显示顺序与用词

1. 任务归属：目标 `账号@主机:端口`、运行标识、当前轮次。
2. 摘要：当前任务的简短进展说明；标注为模型整理，不暗示全部结论已验证。
3. 已确认事实：宿主匹配的前台返回与退出码，链接或展开对应动作证据。显示“前台返回，退出码 0”，不能替换为“业务成功”。
4. 依据输出整理：模型对保留输出的解读，明确提示“尚非独立核验”；同时展示依据的命令。
5. 待核实假设：模型提出的可能性；不能采用与事实相同的成功样式。
6. 剩余步骤：待做、进行中、受阻、模型标记完成。步骤状态是模型报告，不授予执行权限，也不代表远端目标已验收。
7. 证据：命令、发送状态、前台完成状态、退出码、输出摘录、截断／缺口标记。终端输出始终是不可信数据。

没有取得证据时显示“尚无可确认事实”，不要用模型开场计划填充事实区。证据为空时也不能自行补造“无异常”。

### 1.2 状态变化

- 每轮摘要更新后，界面与下一轮请求使用同一份当前快照。更新不得先显示未通过验证的模型字段再异步纠正。
- 摘要更新可单独发生，不代表已经发出命令。用户能区分“上下文更新”和动作卡片。
- 暂停显示阻塞原因及尚未确认的结果；取消显示“AI 已停止”，保留最后已知信息。已发出的远端操作不因此撤回。
- 切换聊天只切换显示，不把另一个任务的摘要带入当前任务；切回仍查看原快照。
- 新运行从自身上下文开始。旧运行、旧会话和历史恢复的信息只供阅读，不能自动接续执行。
- 若证据或摘要因容量上限被裁剪，显示“仅保留有限摘要／证据”，不隐藏其不完整性。

本版不提供自由编辑“已确认事实”的入口，以免本机状态与用户文字混成一种事实。用户需要修正任务方向时，使用原有停止／重新开始流程；不要为了编辑摘要绕过任务所有者规则。

## 2. 终端选段分析

### 2.1 入口与预览

终端有选择时启用“发送给 AI”。点击后只建立内存草稿；没有选择时按钮不可用或解释“请先选择终端文本”。不得默认选取全部回滚内容。

预览显示以下内容：

- “终端摘录”文本编辑框；每聊天最多一份待发送选段。
- 固定来源：主机、端口、账号、会话 ID 和 generation。来源由选择时的终端快照带入，不能通过编辑文本改写。
- “用户已编辑”标志；若发生截取则显示“原选区超限，仅保留当前预览内容”。
- 目标聊天、模型名、模型服务地址及本次发送范围。
- 允许用户补充分析问题；不自动把问题解释为执行许可。
- 本次确认控件、发送和取消。

选段上限为 **8192 UTF-8 字节且最多 200 行**。中文和其他多字节字符以字节上限校验，不仅使用 JavaScript 字符数。截取必须保持合法字符边界，实际将发送的内容须在预览中完整可见。

### 2.2 确认与发送

文字聊天的一般接收方确认和终端选段本次确认分别处理。预览中的同意只能覆盖当前选段最终文本、其来源、当前聊天及当前模型配置；不能通过之前已经同意聊天来跳过。

以下操作撤销本次确认：编辑选段、替换选区、更改分析问题中属于待发送数据的内容、更换模型配置或目标，以及 SSH 重新连接／切换。显示来源不匹配时，发送按钮不可用，并提示重新选取与核对。

点击发送时再次核对当前在线 SSH generation、聊天来源、历史只读状态、模型配置版本、字节限制和任务占用。复用普通文字聊天发送通路，把来源和“用户编辑的终端摘录”标签作为普通文字数据序列化。不会调用终端任务启动接口，也不会改变风险许可。

正在执行终端任务的聊天沿用原有占用限制。选段不隐式插进正在执行任务，不抢占写入权；可以保留草稿供用户处理当前任务后再核对。

### 2.3 取消、失败与秘密

- 取消预览不发模型请求、不写 SSH、不启用操作日志；已发送的数据无法靠取消撤回。
- 明确报错时保留可查看草稿，并重新核对后才能重试；发送状态不确定时不自动再次发送。
- 预览提醒“请删除密码、令牌及敏感内容；自动脱敏并不完整”。已知秘密继续使用宿主脱敏，不能宣称预览即保证脱敏完成。
- 本机用户可编辑选段，因此它不是远端证明、审计记录或自动完成凭据。

## 3. 终端搜索

- 工具栏搜索按钮与 `Ctrl+Shift+F` 打开搜索条。实现可以兼容平台常用修饰键，但本版 Windows／Linux 必须验证 `Ctrl+Shift+F`。
- **不得拦截 `Ctrl+F`**。终端聚焦时它仍交给远端 Shell 做光标移动；`Ctrl+C` 保持原中断语义。
- 搜索输入框获得焦点后，提供上一个、下一个和关闭；Enter／Shift+Enter 可对应下一个／上一个，Esc 关闭并返回终端焦点。
- 有结果时定位本地缓冲中的匹配；没有结果时显示“当前终端缓冲未找到”。不声称检索了已经滚出缓冲的历史。
- 搜索输入不写入终端，不发送模型，不读取日志数据库。内容仍以文本呈现，不解释成 HTML、链接动作或 Shell 命令。
- 会话 generation 改变时清除旧搜索命中与旧选择，不能跨服务器保留可操作的命中。

## 4. 字体与回滚设置

在终端相关设置提供字体大小和回滚行数。范围、默认值见需求文档。展示“仅影响本机显示；降低回滚行数可能丢弃较早的已显示内容”。

修改即时应用于 xterm，并重新计算尺寸；不重建 SSH、PTY 或 AI 任务，不复位 Shell，不重发命令。尺寸变化继续走已有 resize 通路，且绑定当前会话。

偏好使用独立本机 `localStorage` 项 `xyzaishell.terminal.v1`，数据版本为 `1`。只保存显示偏好。读取内容损坏、版本不兼容或写入配额／权限失败时安全回退或保留当前可用设置并提示；不能因此影响手动终端。不同进程窗口无需强行同步运行中的显示状态。

## 5. 复制与粘贴

- 明确的复制入口只处理当前选择，不在远端输出出现特殊序列时自动写剪贴板。
- 保留 `Ctrl+C` 的 Shell 中断含义，不将它全局改成复制。复制失败应提示，不假装已成功。
- 主动粘贴时显示可核对的文本预览及目标，说明多行、换行和控制字符可能让远端立即处理输入。确认操作应区别于“发送给 AI”。
- 粘贴提交绑定打开预览时的会话 generation；重连、断开或换目标后旧确认无效。
- 确认后仅使用当前手动输入队列，不额外追加 Enter；已有换行仍可能触发执行，不能承诺“粘贴不会执行”。
- 取消不读入 PTY；剪贴板不可用时给出本机权限／环境相关提示，不能退而启用远端自动剪贴板功能。

## 6. 模型检查界面

模型设置分开提供“文字连通测试”和“任务工具调用测试”。两者先使用确定已保存的配置，再核对该次目的、目标和发送范围。设置的普通“保存”不发送测试请求。

工具调用测试的确认文案需说明：只发送固定测试提示和模拟工具定义；服务可能记录请求或计费；不发送聊天／终端内容；测试不会执行工具或 SSH 命令。

结果按测试种类分别显示，至少包括所测服务、模型、配置版本和以下语义：

| 结果 | 用户可理解的含义 |
| --- | --- |
| 本次支持 | 本次完整流式工具响应符合当前适配器要求 |
| 本次不兼容 | 收到可判断的工具响应，但数量、名称、参数或结束协议不符合要求 |
| 未能判定 | 连接、认证、超时、取消或缺少可判定调用；不能认定该模型永久不支持 |

保存新配置或重新加载后，旧结果只能显示为旧配置的结果，不能作为当前通过标记。取消与重复点击沿用单一活动测试及取消防迟到机制。文字测试通过后，工具测试仍独立显示其状态。

## 7. Shell 诊断界面

在现有“命令状态识别”面板保留当前阶段与显式启用入口，增加具体原因和下一步。错误码可复制用于反馈，但不能展示包含秘密的完整环境变量、trap 内容或原始异常。

例如：

- Bash 版本／模式不支持：显示实际已知的限制，不建议自动创建替代子 Shell。
- trap 或动态提示符不兼容：请用户核对自身配置；软件不自动删除或覆盖。
- 命名空间冲突、hook 属性不支持或工具缺失：说明具体类别与验证范围。
- 超时、断线、协议缺口：说明结果未知和自动输入已暂停，不提供会盲目重发脚本的按钮。

关闭诊断面板不等于故障消失，不能恢复派发。日志记录开关仍独立，打开诊断面板不会开启日志。
