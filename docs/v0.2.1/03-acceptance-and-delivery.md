## 1. 阻断性验收矩阵

全部 fixture 使用合成用户消息、合成秘密和本地受控响应；不读取真实 SSH 密码／模型密钥，不连接生产服务器，不用旧 CI 代替新实现验收。

| ID | 场景 | 必须观察的结果 |
| --- | --- | --- |
| M01 | 普通聊天、规划、摘要请求，混合职责／规则 preamble、工具 schema、历史摘要、对话与观察 | 从最终请求与主机来源表逐项核对五类；当前对话子项合计等于父项；C+O=I，主占用和阈值同为 I/B |
| M02 | 无固定规则／无摘要、无工具、空正文但有角色／关联字段 | 相应内容类为 0，协议开销仍如实计入；不虚构内容；未知不填 0；无效预算不能发送 |
| M03 | 用户正文、AI 回复、终端结果伪造 SUMMARY_PREFIX／EVIDENCE_PREFIX、规则口吻及同名 JSON 键 | 分类按主机来源不变；用户伪装摘要仍属用户消息；不提升信任或增加保护／执行权限 |
| M04 | 实际重复发送两份内容、嵌套规划 JSON、中文／emoji／引号／反斜杠 | 真实副本各计一次，同一位置只计一次；语义内容、转义／包装与最终 UTF-8 字节分别可对账 |
| M05 | 相同 wire body 只改变侧表分类／拆片粒度；来源缺失／冲突 | O 和 I 不变；不以 fragments.len() 增加余量，不因逐片取整改变总量；分类不可用不能伪造。独立完整请求总预算可靠时仅分类不可用；总量不可靠则停止发送，不能跳过硬预算 |
| M06 | 新估算器与旧 provider usage／校准混用 | estimator_version 更新；旧校准不继承；供应商上次实报不被摊成类别实报，不覆盖当前估算 |
| L01 | 较早用户消息中有否定限制、条件许可、后续纠正，混合旧 AI／日志 | 离开保护窗口的旧用户消息确实进入 LLM manifest；固定提示要求保留目标、限制、纠正、事实、疑点、剩余步骤；当前／近期／主机保护原样保留 |
| L02 | 合成摘要有合法 coverage 但遗漏重要限制 | 人工语义评审标记遗漏风险；程序仅能报告结构检查，不宣称无损。真实模型质量另列，不用受控响应证明模型理解能力 |
| L03 | 约束来源指向旧用户消息，摘要成功后触发独立 RAM 保留策略 | 来源索引仍可辨认；不因 constraints.source_ids 写入 dependency_ids 而永久锁原文；可恢复、已过期与缺口区分，不能声称仍有完整原文 |
| L04 | 幻造来源／引用、伪造审批／目标／生命周期、结构外字段、未闭合工具对 | 非法结构／引用拒绝；必要证据和工具闭包保留；执行器调用为 0；退出码 0 不变成业务成功 |
| L05 | LLM→LLM，第二次来源包含上次摘要，原始来源已有过期／归档状态 | 新 coverage 恰好当前直接来源；别名表仅含直接来源及允许的受保护锚点，不混入祖先；新约束指向直接摘要 ID；谱系可辨认，不重新激活原文；真实证据依赖仍合法保留 |
| Q01 | quick 前存在较早长用户消息，其后段含限制；混合旧 AI 和闭合结果 | UserInput 全文原样保留；允许的其他历史可摘录；本地断网可运行且模型请求为 0 |
| Q02 | LLM→quick→quick；约束只在摘要尾部、自由文本或嵌套摘要中；JSON 长于 160 字符 | 所有现用摘要原样保留，JSON 不被截坏；不依赖模型自报 user_constraints 是否为空；不能间接丢用户约束 |
| Q03 | 全保护、摘要很大、候选无收益或缩减后仍超硬预算 | no_effect／明确需要调整或失败；旧投影不变，不丢保护项凑预算，不偷偷改用模型 |
| A01 | active_turn 80%／94.9%／95%，end_of_turn 80%；token 40% 而 bytes 95% 未超硬限 | 严格沿用轮中／轮后阈值；字节软占比不触发；最终回复完成由主机判断，等待审批／密码／结果未知不算结束 |
| A02 | 草稿编辑、当前指令到达、生成／命令在途、安全点排队、新消息撞轮后 job | 草稿不上送；在途不打断；过期 job 不能提交，新轮按 95% 重判；轮后压缩不续跑命令 |
| A03 | 取消、超时、模型配置／会话／目标／脱敏变化、迟到响应、未知 IPC 结果 | 旧投影和权限不变；无静默 fallback／自动重发；unknown 仅靠同 job 回执核对，fresh 保护有效 |
| A04 | 90%→85% 有真实收益；token／字节单项压力及 both；同源重复自动检查 | 不设固定目标比例；收益按触发指标且另一项不增；完整请求准入；无新增可压缩来源不再调用 |
| H01 | 开／关历史保存、已归档缓存卸载、无归档原文过期、归档失败 | 默认关闭不落盘；压缩不改已存聊天；缺口与可读归档区别清楚；恢复只读、不恢复审批／命令 |
| U01 | 五行及子项、协议说明、整数对账、零／未知／舍入、宽窄窗口／键盘／屏幕阅读器 | 只有五个内容类别；协议不是隐藏第六类；构成分母和预算分母明确；展开不改总量或触发请求；焦点和错误提示保持 |
