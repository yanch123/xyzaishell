### 安装后的原生程序

平台为 Ubuntu 22.04、Ubuntu 24.04、Windows Server 2022。共核对 15 个原生结果文件，各平台均包含首次安装／重启、同版本重装、卸载重装、公开 v0.1.4 基线安装与实际升级。

首次安装场景通过真实界面和原生 IPC 验证：

1. 默认 256K 容量、占用及分类显示；简洁模型设置及高级项默认折叠。
2. 快速压缩有正向 token／请求字节缩减，且不调用模型。
3. LLM 压缩实际向受控本地兼容服务发送 HTTP 请求；响应被暂挂时由用户界面取消，先观察取消状态，再释放响应。重试产生新的请求并成功缩减上下文。
4. 压缩后 12 条原始聊天消息仍可读取。
5. 持久存储恰有两个成功记录（quick 与 llm），有正向缩减及一致的有序来源索引；取消不伪造成功记录。
6. 重启／恢复只读文字，不发起模型请求，也不恢复执行权限。

## 3. 明确边界

- 原生压缩使用受控 OpenAI 兼容服务，不是用户的真实模型供应商。摘要语义质量及不同第三方模型的行为仍需真实使用验证。
- 未覆盖 Windows 10／11 实机、桌面输入法、原生界面的跨多页历史浏览，或在已安装 GUI 内完成 SSH 登录与完整 Agent 操作。真实 SSH 核心与原生 IPC 分别验证，不能冒充一个已完成的 GUI 全链路测试。
- 较早的用户消息当前仍完整保护。是否允许模型整理这些旧消息等待确认；在此之前，用户输入占满保护预算时会明确停止，不能承诺任意长对话都能压缩。
- 原始对话归档与动态上下文分开；未开启历史保存时不会偷偷落盘。磁盘和受管理 RAM 均有独立上限，不能解释为无限保存或整个程序的 RSS 保证。
- 仅 dev 开发交付，没有合并 main、创建 v0.2.0 标签或发布 Release。CI 中的安装包属于测试构建，不等于正式发布。
