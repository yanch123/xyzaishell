# 01 — 实现与本地检查

日期：2026-10-16。本记录对应首次 v0.1.4 实现阶段，不是公开发布验收。精确提交与平台 CI 在推送后补充。

## 已实现范围

- 统一对话提交入口；无连接／未就绪仍能聊天，已就绪时模型可自然回复或提议命令。
- 一次配置和当前目标范围的能力同意，替代每任务确认；危险动作仍使用原精确批准通道。
- 当前聊天前文及有界任务结果进入后续分析，历史字段先脱敏后编码／裁剪。
- 连接阶段同一可见 PTY 的受控 Shell 启动，临时 rc 读取 .bashrc 后准备识别；无 bootstrap stdin 注入。
- 前端一个输入框、内联动作／事实步骤、明确状态，不再以“尚未启用”混同实际忙碌。
- v0.1.3 公开安装包作为固定升级基线；候选 UI 测试新增无 SSH 连续对话和历史保留。

## 本地检查与限制

截至本记录编写时：前端类型检查与生产构建通过；205 项前端测试通过；核心 Rust 全套通过（254 个单元、26 模型聊天、23 SSH、16 终端 Agent、2 统一对话；已有 ignored 独立说明）；严格 Clippy、格式检查通过；81 项 Python 管线测试通过。后续修正必须重新运行相关检查，最终数量以最终执行记录为准。

20 项实际 Bash 5.2 PTY 验证覆盖别名／函数／提示符钩子、非登录启动、前台读取和程序阻塞时零自动输入、断线及不支持环境；Bash 5.1 由 CI 矩阵验证，不能仅凭 5.2 通过宣称完成。

本地真实 OpenSSH 验收已尝试但受 OS PTY chown 错误阻塞；没有跳过并记为通过。浏览器运行受本地 Chromium socket 权限环境错误阻塞；测试发现与前端构建通过不等于截图或浏览器通过。Windows/Linux 安装包、原生生命周期、真实版本升级与浏览器截图仍等待精确提交 CI。

## 发现并修正的风险

统一提交改变了旧任务入口：必须保留 IPC 结果未知时的防重复提交，不能只依赖“不会自动重试”。独立审查以提交响应和核对读取同时丢失复现了重复调用风险，已增加提交不确定状态及四项回归测试。只有更新的权威聊天记录证明该条输入已接收，才消费原草稿并解锁；读取失败或状态不明不允许重发。若脱敏使原始输入无法精确匹配，保守地保持阻止状态。

普通空 .bashrc 在启动 rc 阶段尚未获得 Bash 后置默认 HISTSIZE，已增加只读推断与实际 Ready 比对，并通过无 .bashrc、最小配置和显式值的真实 Bash 5.2 PTY 回归；不能修改显式空值、零或无效值来绕过限制。

上述修正已完成本地回归；正在推送整合候选以获取平台证据。本文件不意味着 main 已合并、标签已创建或安装包已发布。

新增统一对话三轮浏览器回归已纳入 CI：问候→普通命令显示后执行→基于结果追问，检查单输入框、单次范围确认、消息不重复。当前发现 16 项浏览器用例；尚不能以发现数量代替运行结果。
