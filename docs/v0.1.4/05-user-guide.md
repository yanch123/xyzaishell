# v0.1.4 使用指南（开发草稿）

> 尚未发布。本文先记录初版统一对话操作；通用命令、旧 Bash 兼容和精简交互须在新版设计落地后同步更新，不能当作已验收功能声明。

xyzaishell 把 SSH 终端和 AI 助手放在同一个窗口。左侧是当前服务器的交互终端，右侧可进行文字讨论、分析选中的输出，或启动需要实际操作服务器的 AI 任务。

本文覆盖从安装到日常使用的完整流程，无需先阅读旧版指南。可下载版本及验证范围以 [GitHub Releases](https://github.com/yanch123/xyzaishell/releases) 为准；快速开始见 [README](../../README.md)。

## 1. 下载与安装

在 Releases 中阅读所选版本说明，展开 Assets，选择安装包，而不是 Source code：

- **Windows x64**：运行 `.exe` 安装向导。需要 Microsoft WebView2，未安装运行时的电脑可能需要联网。
- **Ubuntu 22.04 / 24.04 x64**：下载 `.deb`，在其目录运行 `sudo apt install ./实际文件名.deb`，随后从应用菜单启动。需要系统 GTK / WebKitGTK 运行依赖。
- 可使用同版本的 `SHA256SUMS.txt` 核对文件；校验和不等于代码签名。macOS、ARM、其他 Linux 发行版暂不在支持范围内。

当前为预发布测试版，Windows 安装包未签名，可能出现发布者或 SmartScreen 提示。遇到安全警告应先停止并核实来源。Windows 10 / 11 实机、Ubuntu 完整桌面使用流程和外部模型供应商兼容性尚未完成验证，请先在测试服务器使用，不要直接进行关键生产操作。

安装后的桌面应用才能建立 SSH 连接。手动 SSH 不依赖 AI 模型；设置、连接管理和日志面板不会锁住终端。

## 2. 连接和管理服务器

### 新建连接

1. 点击“新建连接”，填写主机、端口（默认 `22`）和用户名。
2. 选择密码或本机私钥认证。私钥填写本机绝对路径；加密私钥还需口令，不应假设未经验证的私钥格式或认证方式兼容。
3. 如果只使用一次，不勾选“保存连接”。如需复用，勾选并填写名称。
4. 点击“连接服务器”。需要保存的资料会先保存再连接，网络失败不会撤销已保存资料。“仅保存连接”只保存，不访问服务器。
5. 首次连接或主机指纹变化时，通过可信渠道核对后再决定是否信任。指纹变化可能有风险，不要仅为解决连接失败而接受。

### 保存连接与记住密码

保存连接资料与保存密码是两个选择。只有明确勾选“记住密码”或“记住私钥口令”，才会持久保存对应凭据。已有秘密不会回填到编辑框；无口令私钥无需勾选记住口令。

- Windows 使用当前用户的系统保护（DPAPI）。
- Linux 使用可用且已解锁的 Secret Service；失败不自动回退为明文。
- 系统保护不代表绝对安全，本机账号或系统被控制时仍有风险。可不保存凭据，下次连接时再输入。
- 私钥文件只由本机 SSH 认证读取，不发送给模型。

在“连接管理”编辑、重命名或删除连接。保存修改不会自动连接；修改认证目标时需重新核对凭据。删除连接资料不会断开当前连接，也不删除私钥文件、主机信任、聊天历史或日志；备份或系统存储中的孤立凭据条目可能保留。

保存冲突或结果不确定时，先重新读取并核对，不要反复保存覆盖。系统存储暂不可用时，已有引用会保留，可在连接时明确选择临时输入凭据；资料编辑仍可使用。

### 多台服务器与重新连接

一个窗口对应一个独立进程、一条 SSH 会话和一个交互终端。已有连接时，新建或连接另一目标默认打开独立窗口，原窗口继续工作。

明确选择“在当前窗口切换”后，应用会请求停止 AI 并断开旧连接；切换失败不会自动恢复旧会话。“连接 → 重新连接”会重新核对保存资料，必要时询问凭据。重连后会重新自动准备命令状态识别，不能沿用此前批准。

## 3. 配置模型和测试连接

打开“设置 → 模型”，填写服务提供方给出的三个字段。当前使用 **OpenAI-compatible Chat Completions** 接口：

- **Base URL**：HTTPS API 根地址，通常以 `/v1` 结尾，不追加 `/chat/completions` 或 `/responses`。示例占位地址不能直接使用。
- **API Key**：对应服务的有效密钥。
- **模型名**：服务支持的精确模型标识。

点击“保存”仅写入本机配置，不发送模型请求。已有 Key 留空表示保持不变；清除请使用“清除已保存 Key…”，确认后保存才生效。更换服务地址时，需要新 Key、清除旧 Key，或明确确认将已有 Key 用于新目标，不能默认复用。

### 测试范围

选择“文字连通性”或“任务工具调用”，点击“保存并测试”；已有配置也可点击“测试已保存配置”。核对接收方、模型和发送内容，勾选同意后点击“确认并测试”。

- **文字连通性**：发送固定短消息，检查流式文字回复，不检查工具调用。
- **任务工具调用**：发送固定模拟消息、工具声明与参数，只验证返回格式，不执行工具、不连接 SSH。

两种测试都不发送聊天历史、聊天草稿、终端内容或 SSH 登录资料，但会使用 API Key 向该服务认证；服务可能记录请求或收费。

结果可能是通过、格式不兼容或无法确定。网络、认证、超时、取消或未完整返回等都可能造成不确定，不能据此判断模型不支持。聊天测试通过不代表任务工具兼容，模拟工具测试通过也不保证真实任务安全或可靠。保存成功后测试失败不会撤销配置；更改配置后，旧测试结果不证明新配置可用。

### 配置文件与密钥保护

展开“高级配置与安全说明”可查看实际路径、权限要求，并使用“重新加载模型配置”。API Key 以明文写入受限权限的本机 `model.toml`，不使用 SSH 的系统凭据存储。不要放入 Git、同步盘或共享目录，也不要将密钥或整份配置发给 AI。

默认路径：

- Windows：`%APPDATA%\xyzaishell\model.toml`
- Linux：`$XDG_CONFIG_HOME/xyzaishell/model.toml`，未设置时为 `$HOME/.config/xyzaishell/model.toml`

Linux 私有目录应为 `0700`、文件为 `0600`；Windows 使用仅当前用户及系统管理员可访问的本机目录。高级用户可用 `XYZAI_MODEL_CONFIG` 指定绝对文件路径，修改后需重启；重新加载只读取本次进程已选定的路径。应用不会用 `OPENAI_API_KEY` 等环境变量覆盖文件设置。本机回环 HTTP 仅在高级文件显式允许时可用于测试。

界面保存会保留已有合法的请求限制等高级字段，完整格式见 [模型配置示例](../../config/examples/model.example.toml)。文件损坏、冲突或保存结果不明确时，先重新读取并核对，不要连续覆盖。正在进行的请求继续使用启动时的配置。

## 4. 在一个对话框中使用 AI

右侧只有一个消息输入框。直接说需求，AI 可以自然回复，也可以在当前服务器执行命令，不需要选择“聊天”或“执行任务”。例如“你好”正常回复，“检查磁盘空间并解释结果”可生成检查命令。

首次发送或模型配置／目标服务器变化时，核对模型接收方、服务器、数据范围和普通命令自动执行许可。确认适用于当前配置与目标范围，后续消息不再重复弹任务启动确认；危险命令始终单独批准。连接变化会使旧动作批准失效。

未连接、正在准备或环境不支持时仍可聊天，本轮不提供执行工具，也不把消息自动排队到未来连接后执行。看到可执行状态后，如仍需要实际检查，可重新明确提出需求。

### 分析选中的输出

在终端选中文字，点击“选区交给 AI…”，核对固定来源、预览、模型接收方和当前聊天历史范围，可以修改或移除附件。勾选本次发送同意后再发送。选区最多 8 KiB / 200 行，截断会标注。

带选区的消息用于文字分析，不会执行其中的命令。若希望执行分析得到的建议，再单独发一条明确需求。编辑、换聊天、重连、模型变化后需重新核对，来源不匹配时应重新选择。过滤不能识别所有秘密，请自行审阅。

## 5. 连接后的自动准备

支持的服务器连接后会自动准备命令状态识别，不需要手动点击“启用”。顶部状态和“工具 → 命令状态识别”可查看准备结果。

- 正在准备／等待提示符：启动初始化尚未完成，AI 不向终端派发命令。
- 可执行：已收到当前连接的独立就绪事件。
- 前台命令运行中：等待本条命令结束和下一次就绪。
- 不支持／状态未知：查看具体原因；手动终端仍可用，不自动重试启动脚本或未知命令。

本版目标覆盖 Bash 4.2.46、5.1、5.2；当前仍待修订实现和实际验收，不能据此宣称全部可用。应用在同一个可见 SSH 终端启动受控的非登录交互 Bash，读取 `.bashrc` 后启用临时识别，不写远端启动文件，不安装服务，不把初始化脚本粘贴到终端输入中。这个启动方式并非完全等价于原登录 Shell 的 profile 初始化；SSH 服务本身也可能先运行账户 Shell 的启动逻辑，`.bashrc` 应正确区分交互与非交互启动。

既有别名和受支持钩子保留。需要开启 history、cmdhist、promptvars、interactive_comments，HISTIGNORE 为空，histchars 为默认值；提示符不安全展开、非 EXIT trap、functrace／extdebug／errexit 等可能不受支持。应用不会为了通过检查修改这些设置。

如果启动脚本正在询问输入，应先在左侧处理；程序不会向密码提示或前台程序盲目输入初始化脚本。准备超时或状态未知时先确认远端实际状态，再决定是否重连，不能盲目断开正在工作的程序。重连不会恢复旧任务或批准。

## 6. 命令执行、上下文与停止

普通受支持命令先展示，再自动交给左侧同一终端；AI 根据返回结果继续分析或下一步。不是所有看起来只读的复杂语法都能自动通过，未知风险操作会暂停。

危险命令显示完整命令、目标与风险，批准只适用于该动作，修改命令或连接后不能复用。自由文本回答不等于命令已执行，退出码为 0 不等于业务目标成功。

执行过程中发送给模型的内容包括本次指令、当前聊天的有界历史、命令与结果摘要、有限终端输出。不会自动发送启动前整个终端历史；模型服务可能记录内容或收费。

“已确认事实 / 剩余步骤”可查看有来源的模型结论、待验证推测和计划；程序识别的返回与退出码单独列出。摘要和输出均有容量限制，不能替代完整日志。后续追问可参考本聊天前文，旧文字不证明当前服务器状态，跨服务器和恢复历史不转移执行权限。

多个聊天共享同一终端，一次只有一个 AI 写入者。避免手动输入与 AI 同时进行。“停止 AI”停止后续生成和写入，不撤回已发送命令，也不自动 Ctrl+C；需要中断时使用终端“发送 Ctrl+C”，再核实结果。断线也不保证远端程序终止。达到轮数上限时先核对进展，再明确提出新请求，不会自动重发。

## 7. 任务中的密码和令牌

不要把秘密值写入聊天或用途栏。模型需要凭据时，只提出字段名和用途；每个任务使用独立的本机秘密文件。

1. 在“任务专用秘密文件”区域点击“准备本机秘密文件”。
2. 用本机编辑器打开界面显示的文件，填写对应字段的 `value` 并保存。
3. 点击“重新加载已填写状态”。界面和模型只接收字段名、是否已填写等信息，不得到秘密值；模型也不会得到本机文件路径。
4. 需要输入远端时，确认终端正在等待正确程序的密码输入，而不是普通 Shell 命令行。
5. 选择“本次输入字段”，填写用途，核对目标和远端回显风险，点击“核对本次秘密输入动作”。
6. 阅读生成的动作卡片，再单次批准输入。

只支持单行秘密值并追加一次 Enter，不能用来拼接任意 Shell 命令。文件修改、重载、连接变化或动作取消后，旧动作失效，需要重新核对。

任务秘密文件是受限权限的明文文件，不是保险库。编辑器备份、同步软件和远端程序仍可能记录、回显或转发秘密；脱敏无法保证识别所有变形、编码和未知秘密。无法确认输入目标时请手动处理。

## 8. 搜索、复制粘贴和显示设置

- **搜索**：点击终端“搜索”或按 `Ctrl+Shift+F`，输入文字后用上下按钮或 Enter / Shift+Enter 定位，Esc 关闭。只搜索本窗口保留的回滚内容，不搜索远端文件。Ctrl+F 保留 Shell 原有行为。
- **复制**：选中文字后点击“复制选区”或按 `Ctrl+Shift+C`。Ctrl+C 仍用于终端中断。
- **粘贴**：点击“粘贴…”或按 `Ctrl+Shift+V`，核对预览与目标后点击“确认粘贴到终端”。换行可能立即执行命令；应用不会额外追加 Enter。粘贴上限为 16 KiB，不允许不安全控制字符；连接变化时旧预览不能继续发送。
- **显示**：在“设置 → 终端”调整字体大小（10–28 px）和回滚行数（500–20000），也可“恢复终端默认设置”。缩小回滚范围会丢弃更早的屏幕内容，不删除远端文件或操作日志。

剪贴板访问失败会提示错误，不要将失败当作已复制或已粘贴。若偏好保存失败，本窗口仍应用设置，但关闭后可能恢复默认值。

## 9. 记录、查看和导出操作日志

### 开始与暂停记录

日志独立于 AI，默认关闭。先按第 5 节确认命令识别已自动准备并就绪，再打开日志面板，明确同意本次本机明文记录，点击“启动终端日志”。日志面板不会自动启用或重装命令识别。

AI 命令按实际动作封装记录，手动命令按对应 Shell 的识别能力记录；不能识别的手动语法标注缺口。记录包含命令、时间和远程工作目录等信息，不保存终端输出，不自动发送给模型。命令可能含密码、令牌或业务信息，脱敏不能保证识别全部秘密。

“暂停记录”只停止记录，不关闭正常工作的命令识别；“恢复记录”不会补录暂停期间的数据。只记录当前 Shell 的顶层命令，嵌套 Shell、环境变更或断线可能产生缺口，不应将日志当作不可篡改审计。

### 查看与筛选

- 工具栏“当前终端日志”：当前会话。
- “连接管理 → 操作日志”：所选连接的历史，包括离线记录。
- “查看 → 操作日志”：全部连接与离线记录。

可按原主机、原账号和关键词筛选，点击“筛选 / 刷新”应用条件并纳入新记录。切换查看范围不会改变记录开关。

记录保留原主机、端口、账号和会话，连接更名不会重写旧记录。缺少档案 ID 的旧数据会显示“档案关联未知”，不会按名称猜测归属。离线查看和导出不连接服务器，也不自动开始记录。

### 导出文件

1. 选择范围，填写所需筛选条件并点击“筛选 / 刷新”。
2. 点击“导出 JSON”或“导出 CSV”。导出当前查询快照内的全部匹配记录，不限当前页；想纳入新记录先刷新。
3. 完成后查看完整本机路径，可点击“复制路径”，再到该位置取用文件。

导出写入本机固定私有目录，不覆盖旧文件。CSV 会处理可能触发表格公式的文本，需要规范文本时选择 JSON。日志不是可直接执行的脚本；分享前仍需自行检查和移除敏感内容。

## 10. 聊天历史与隐私

打开“设置 → 历史记录”，勾选明文保存同意，点击“启用明文聊天历史”。默认关闭，每次启动需重新选择。启用后保存当前及后续聊天的脱敏文字到本机明文数据库，不保存原始终端输出或可重放的授权；已主动发送到聊天里的选区文字仍应作为聊天敏感内容审阅。

- 点击“仅恢复文字”只恢复阅读内容，不重连 SSH、不启动模型、不批准动作或重发命令。历史摘要不证明当前远端状态。
- “停止保存聊天历史”只停止新增保存，不删除旧记录或文件。
- “移除历史”需要核对记录后单独确认，逻辑删除不可恢复，也不保证磁盘、备份或其他副本被物理擦除。当前打开的聊天仍在内存中。
- 多实例保存冲突、损坏或移除结果不确定时，先重新读取列表核对，不重复提交。

状态目录与模型配置分开：Windows 为 `%LOCALAPPDATA%\xyzaishell\state`；Linux 为 `$XDG_STATE_HOME/xyzaishell`，未设置时为 `$HOME/.local/state/xyzaishell`。

SSH 记住的凭据使用系统保护；模型 Key、任务秘密文件、启用后的聊天历史和操作日志各有不同的本机保存方式。不要将“本机保存”理解为已经加密，也不要将脱敏理解为所有秘密均已清除。关闭历史或日志不会撤回已发送给模型服务的内容。

## 11. 常见问题与故障处理

**没有模型能用吗？** 可以手动连接 SSH、操作终端。聊天和 AI 任务需要先配置模型。

**模型配置读不到或保存失败？** 在“高级配置与安全说明”核对实际路径、权限和文件格式；如使用 `XYZAI_MODEL_CONFIG`，须为绝对路径，修改后重启。冲突或结果不确定时先重新加载核对，别反复覆盖。

**能聊天但不能执行任务？** 检查 SSH、命令识别就绪状态、是否有其他任务占用终端，再运行“任务工具调用”测试。文字连通性通过不代表支持所需的流式工具调用。

**命令识别提示不支持？** 查看第 5 节和面板说明。支持 Bash 版本不代表所有自定义配置兼容。应用不会为了通过检查自动修改远端 Shell 配置，仍可使用手动终端。

**AI 等待批准或停住了？** 分清危险操作批准、等待前台返回和状态未知，回到实际终端核对。不要重发结果未知的命令，不把模型自由文本当成已执行的证明。

**“停止 AI”后程序还在运行？** 已发送命令不会被撤回。必要时在终端发送 Ctrl+C，再确认远端是否真正停止；断开 SSH 也不保证停止。

**SSH 凭据保存失败？** 核对系统安全存储是否可用、已解锁，或仅使用本次凭据。不会自动以明文回退，已有凭据引用会保留。

**日志导出按钮不可用，或找不到新记录？** 修改筛选后先“筛选 / 刷新”。日志默认关闭，不补录启用前或暂停时的命令；浏览历史不等于已开启记录。

**为什么旧聊天只能阅读？** 恢复历史或切换到另一服务器后，旧聊天不能复用现场上下文和批准。请选择当前目标的新聊天，重新核对并启动任务。

**可以传文件或操作本机吗？** 当前只通过 SSH 终端操作远端，不提供 SFTP、文件上传下载、本机 PowerShell 或 WSL。

底部消息面板汇总连接、配置等结果，不替代命令日志或聊天历史；标记已读或关闭消息不代表批准待办动作。

反馈问题时提供应用版本、系统版本、脱敏错误码、界面状态和复现步骤。不要上传真实 API Key、密码、私钥、任务秘密文件或包含秘密的截图。
